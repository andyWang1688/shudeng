# 历史资料

本目录用于追溯，不是当前开发指令。日常从[开发导航](../README.md)进入；当前产品、架构、设计正文与归档冲突时，按当前规范及其明确的取代关系处理。

| 目录 | 内容 | 何时读取 |
| --- | --- | --- |
| planning/ | 早期范围、首发决策、RN Spike/迁移计划、旧完整 ADR 与讨论规格 | 查某条决定的演变、原始验收门槛或曾考虑的方案 |
| legacy-ios/ | Swift Agent、旧问答设计与界面评估 | 查原生行为基线或迁移差异 |
| research/ | 竞品、向量模型与 Apple HIG 研究；[HIG 覆盖记录](research/2026-11-06/apple-hig-reading.md)保留完整来源 | 某项选型需要重新核对一手来源，按主题选读 |
| design/ | 按日期保留的旧原型、图片、实施与视觉验收 | 回溯当时已确认外观或具体证据 |
| implementation/、reviews/ | 已完成 Issue 的实施记录与旧代码审查 | 排查历史回归或判断当时限制 |

文件中的“当前”“必须”“通过”等措辞只适用于记录当时的时间、实现和环境。历史源码/测试路径、未随仓库保存的 scratch 证据可能不可用；不能据此推定现状或新增功能。已发布记录仍保留在[releases](../releases/)，近期 RN 证据见[validation](../validation/README.md)。
