## 已读的定义与保存

应用原来只有最后阅读位置和供检索使用的连续截止范围，没有可靠的已读记录。因此不从当前页、最远进度或旧进度迁移出“已经读过”的推断。

- 在“目录与书签 → 已读范围”明确确认已读，可分别勾选第 1、3 项而保留第 2 项未读，也可移出范围。
- 一项对应 EPUB readingOrder 的一个完整正文资源。一个资源可能包含多个目录小节，界面合并显示相关目录标题，并在说明及确认弹窗提示“全部读过才确认”。本票不识别段落级的实际阅读行为；一个正文文件包含整本书时，也只能确认整项。
- 打开书、正常翻页、滚动、目录／搜索／书签／引用跳转、返回提问处、重排布局、卷页预取和取消手势都不会调用确认方法，因而不会扩大已读范围。
- 以 EPUB 内容哈希 bookID 隔离，资源序号保存为 Book.readChapters，和其他阅读记录一起原子写入 library.json；索引重建不改该字段。旧书没有此字段时视为尚未确认已读。
- 写入成功后才发布新范围和“已读范围已保存”。失败保留旧范围，界面提示此次未生效，可取消或重试同一确认；重复确认按集合保存，不重复计数。

这属于 #13 对“仅已读”的具体定义：用户明确确认的完整资源集合，不将访问推断为读完。暂不自动记录停留时间、可见段落或连续阅读轨迹。

## 从界面到最终发送

新问题默认整书。每个草稿保存 onlyRead；继续追问继承上一轮选择，重新发起的新对话仍默认整书。生成中和已完成的轮次不能改变本轮选择。

QuestionStore.send 在开始本轮时，从当前书已经提交的 readChapters 建立不可变 BookEvidenceScope 快照并随本轮保存。外部显式传入的截止范围只会与已读集合取交集，不能放宽它。发送过程中再勾选或移出章节影响下一轮，不改写已经开始的请求。

| 路径 | 限制 |
| --- | --- |
| 提问选文 | 必须通过当前书真实来源位置及原文片段校验；越界或过期则整轮拒绝，不静默丢弃选文 |
| 固定邻文 | 仅已读时逐段验证，排除未读邻文；提示可能缺少后文解释 |
| 关键词／语义检索 | bookID、连续截止范围及非连续章节集合共同过滤候选；局部关键词查找也在 SQL 中应用范围 |
| 邻段扩展 | 扩展查询和取 evidence 时重复应用同一范围 |
| 全书问题 | 语言样本、逐章候选、章节窗口及上下文补齐都使用相同范围；“全书”提问不能越过仅已读选择 |
| 最终材料 | 对最终选中片段再次校验；发送的 context 采用已核验 quote，定位前后缀及原始邻文快照留在本机 |
| 空范围／资料不足 | 没有允许的原文样本时，在任何问答 HTTP 前拒绝；允许范围较少时保留“可能缺少后文解释”和取材不足提示 |

BookEvidenceScope.chapters 为 nil 时保留既有整书／连续截止契约，空数组表示没有允许资源。没有变更模型、分块、排名融合或检索质量口径。

## 历史隔离

历史答案可能复述已经看不到的后文，不能仅过滤本次引用。解析追问的第一次 HTTP 之前，核对此前答案的范围是否被本次范围包含，并核验实际发送过的书内依据、引用和选文；旧记录缺少范围时保守按整书处理。

从整书切到仅已读，或移出历史答案曾允许的资源，都会拒绝继续该历史请求，提示扩大范围或新建问题。这里不自动裁剪历史，不删除离线记录，也不将筛过引用的旧答案作为安全历史重新发送。同一允许范围中的追问正常解析指代、重新查书并回答。已保存但本轮不会发送的未读邻文快照仍可留在本机，不参与解析／回答请求。

整书／旧记录的范围未列出有限资源集合，因此即使当前已确认所有资源，也保守拒绝将其答案复用于仅已读追问；需要新建问题。范围记录不证明 AI 的书外知识已经隔离，本票只约束应用查找和发送的本书材料。
