# #9 选文问答、可核查引用与保存

仅首发 T08 的关键词增量。每次阅读选文创建独立 UUID 对话；对话栏提供最小回看与草稿恢复，不提供自由提问、追问、全书概括、仅已读或后台运行承诺。语义检索与这些后续功能仍由 #10—14 实施。

## 原文与请求

- 复用 Readium 真选区和 #8 当前书关键词索引。问题与选文提取至多十个关键词（英文词／中文相邻字符对），每词取前八个出现位置，按 Locator 去重；选文与邻文不依赖搜索命中。不是语义检索，也不保证关键词找到所有必要背景。
- 阅读页从 BODY 递归提取可见连续文本 run；排除 hidden、aria-hidden、display:none、visibility:hidden/collapse、script/style/noscript/template，遇隐藏／块边界切断 run。选区与 run 求交，跨段选文保留所有可见选段，邻文取交集 run 及其前后 run；不遍历 HEAD，不删除隐藏字后冒充原整元素范围。
- 每个片段保存真实文本节点、UTF-16 起止、元素选择器及原始 prefix/suffix。prefix/suffix 用于共用阅读器严格原文校验，可能包含元素内不可见字符，但只留本地定位；网络只发送可见 quote/context、证据编号和章节。不让模型产生 Locator。
- 资料未齐时不静默降级：可等待，或明确选择只用选文与邻文解释。正常路径按当前 book_id 搜索其他章节；回看不构建请求。
- 使用 #7 OpenAI Chat Completions／Anthropic Messages 的非流式文字协议，无工具调用。发送前显示服务名称／地址、可能发送其他章节及费用提示；记录实际发送证据快照、章节、文字量、取证限制和服务格式／模型／名称。切换配置不改写旧完成记录。
- 本地输入预算最终序列化 UTF-8 不超过 24,000 字节，候选预留至 23,000 字节；选文及邻文自身超限则不发请求，额外关键词材料超限则明确记录未发送和依据不足。输出 max_tokens=1600、请求超时90秒，无自动网络重试。服务413、明确上下文错误及 length/max_tokens 截断标为未完成。这个保守本地预算不保证任意模型均接受。

## 引用与往返

回答请求约定普通 JSON 文字，含 answer 和 citations（id、完整 quote）。应用仅接受本次实际发送证据中的编号及完全一致的引文，去重并使用自存 Locator；未知编号、错引文不生成有效链接。格式不符时保留回答文字并明示无有效引用；无引用不冒充书内结论。回答文字不启用 URL 自动链接。

引用展开显示章节、快照与上下文；跳转复用阅读器现有精确可视核验，不以全文 contains 或首次同文查找替代。阅读页“回提问处”返回原选区；历史也可在原文件存在时打开引用，原文不可用时保留快照并明确提示。

## 保存与取消

reading-questions.json 是独立业务记录，不随重建 book-index.sqlite 删除。每个问题一个稳定 UUID，包含草稿、选区、发送材料、回答、有效引用、状态及错误。草稿逐次编辑原子保存；完整回答、关联引用与 complete 在同一文件 revision 提交成功后才显示“回答已保存”。失败时保留内存 pending，界面优先显示尚未保存，重试保存同一 UUID，不调用 HTTP、不追加消息或新对话；最后一次未提交内容不承诺强杀后零丢失。

状态为 draft → preparing → generating → complete；取消／网络失败／容量不足／重启中断为 incomplete。每轮任务持有 token，旧任务仅能清理自己的句柄；取消后立即重新请求不会被旧 defer 或迟到响应覆盖。关闭面板不取消，请求由应用级 store 持有；主动取消保留已经提交的数据。本票非流式协议不会在响应完成前取得增量文字；不引入 #14 的后台调度。

读取失败禁止覆盖及无恢复路径的新建；历史提供读取重试。真实写失败恢复后可重试保存原结果。编排存储接受 AISecrets 依赖，测试统一使用随机 Keychain service，不与正式配置命名空间共用；产品默认仍沿用 #7 原身份及安全存储，不改密钥格式或 entitlement 脚本。

## 验证边界

原创 search-fixture.epub、真实选文／Reader 导航、两种可控本机 HTTP、真实 Keychain、原子文件写故障／SQLite 准备故障及重启盘记录交叉核验。脚本只用虚构凭据，不保存鉴权头。实际命令、分段通过证据、运行包限制、故障清理与设备交接见 .scratch/delivery/issue-9.md；开发验证不替代主控独立验收。真机、真实付费服务／模型回答质量及后台系统行为未验证。
