# 当前产品范围与行为规范

本文定义已确认的产品行为与边界。术语见 [GLOSSARY](../GLOSSARY.md)，重要选择及取代关系见[决策索引](adr/README.md)，聊天中的决定与可执行验收见[基准清单](product-baseline.md)。实现、验收与发布状态分别从[架构](architecture.md)、[验收记录](validation/README.md)和[用户文档](../website/doc/index.md)查询；规范获准不等于已实现或已发布。

## 当前阶段

共享架构面向多端，当前 iOS 优先、Android 暂缓。独立示例 Demo 的整体视觉方向已由用户确认，现进入既有业务接线；Demo 的按钮和反馈不代表产品能力已经完成。视觉基准见 [Demo 说明](../apps/mobile/src/ui/visual-demo/README.md)。2026-11-07 用户批准将独立笔记页归入每本书，取代基准中的全局笔记入口与分组；其他功能范围继续冻结。未来平台保持业务语义，导航、窗口与输入方式按当地平台习惯适配。

## 书架与阅读

书架导入可重排 EPUB 与 PDF，支持书名/作者搜索、排序及移除。固定版式 EPUB 暂缓。点书封进入阅读；已取消“继续阅读”卡片及其最近一本书偏好，但各书阅读进度仍需保存和恢复。

EPUB 保留目录、书内搜索、书签、字号与主题，以及分页、滚动、仿真翻页。阅读正文保持固定布局，控件覆盖显隐；点击隐藏工具栏不触发重新分页、资料加载、阅读器重建或卷页缓存重建。显隐终态不拦截隐藏控件的触控与辅助技术焦点，连续点击按最后意图收敛；真实字体、窗口和主题变化按原文位置恢复。

滚动模式按连续阅读整本书验收：上一章末尾与下一章开头能够在同一视口衔接，单次拖动与惯性自然穿过章节边界，反向拖动也保持原文位置；不以章末再次松手后整屏替换下一章作为完成。章节资源可按需预加载和回收，不要求一次装载全书。目录、搜索、标注和书签回跳后仍应处于同一连续阅读路径。当前已采用多文档引擎并完成 Small 的相邻章节手势验证；长时间连续前向阅读仍存在已读文档增长，不能视为大书性能验收完成。具体范围见[本轮验收](validation/2026-11-09/continuous-epub.md)，选择理由见 [ADR-0022](adr/0022-continuous-epub-engine.md)。

字号与阅读主题的唯一设置入口在书内“阅读设置”，“我的”不重复提供入口。字号直接作用正在阅读的正文，不另放样例文字；阅读主题的选中项、正文与控件颜色、重开后的状态须一致。用户已明确入口位置，但未指定当前书主题必须驱动所有书或整个应用变色；改变这一范围需另行确认，不能把现有两份偏好直接当作产品决定。

PDF 按页面有无可用文字提供能力：文字页支持阅读、缩放、目录、页码/进度、书签、文字标注、搜索与问答；扫描页支持阅读、缩放与书签，不做 OCR、PDF 重排或表格结构还原。同一本 PDF 可以混合两类页面，不给整本书贴“支持等级”。

导入检查完成后再确认书籍入库：正常 PDF 不增加提示；存在扫描页时说明仍可使用的能力，允许取消或继续导入，导入后可在阅读器查看说明。检测的技术限制在工程实现与验收中记录，不用“格式限制”“不是书灯的问题”等文案归责用户。

PDF 不提供 EPUB 的字号、行距调整。当前 iOS 中，未有读者偏好时，200 页及以上默认单页，小 PDF 默认连续；读者可以切换。阈值实现入口为 [usePdfReader](../apps/mobile/src/reader/pdf/usePdfReader.ts)，此策略不是已验收内存上限。

## 标注与书签

| 对象     | 行为合同                                                                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 书内标注 | 顶层目的地为书架、对话、我的，不提供独立笔记栏目。目录弹层提供目录、书签、标注三个分栏；标注合并展示当前书的高亮与笔记，按阅读位置排序，不重复书名、时间或数量。长摘录与正文默认预览；点条目回到原文，左滑提供编辑（仅笔记）与确认删除。搜索覆盖本书全部章节、引文与笔记正文，不受预览或屏幕范围限制。 |
| 标注捷径 | 书架书籍菜单提供查看标注，不要求先加载原文。已移除书籍可直接打开保留标注，原文件缺失不阻断查看、编辑和导出；定位时说明原文不可用。书内及捷径复用相同列表和保存规则。 |
| 标注导出 | 导出当前书的全部高亮与笔记，包括书名、章节或页码、摘录及个人正文；搜索条件不裁减导出范围，不混入书签或其他书。 |
| 高亮     | 四色原文底色；点击已有高亮打开调色板，再点当前选中颜色取消，点其他颜色改色；操作后关闭调色板，取消无二次确认。没有将高亮转为笔记的入口。                                 |
| 笔记     | 带正文，以固定暖色波浪线呈现，无下划线颜色设置；点击波浪线直接编辑，无中间详情层。编辑器 header 提供确认删除入口，空正文禁保存。                                         |
| 笔记保存 | 不自动保存或恢复草稿，不显示草稿状态；关闭即丢弃未保存内容。空正文不能把笔记降级为高亮；若要换类型，先取消/删除原记录再重新选文创建。                                    |
| 书签     | 在阅读器的书签分栏管理，和内容标注分开；点击回位置，保持当前页书签标记。新增仅在原文右上角操作，不在列表重复添加入口。 |

上述标注与书签区分、保存语义沿用 [ADR-0016](adr/0016-annotations-information-architecture.md)，单书归属与入口取舍见 [ADR-0021](adr/0021-book-owned-annotations.md)。容器、颜色值、尺寸和动效按[跨端界面规范](design/ui-development-standard.md)与该端获确认的基准实现；不会因为换组件就改变保存或删除后果。

## 阅读问答与对话

问答可以携带提问选文，也可以直接问当前书；允许参考当前整本书，包含未读章节。没有“仅已读”开关、已读范围管理或跨书架问答。Agent 可多次查书、读原文并核对来源；提问选文负责明确问题指向，不把检索范围缩成选中的文字。全书概括须说明真实章节覆盖，局部命中不能表述为已经读完全书。

阅读内发起新问题新建对话，追问留在同一对话。对话栏目默认历史，按书分组，支持回看、继续、改名与删除。书内引用能回原文；网页来源单独展示并打开真实出处。出处存在不等于回答推断已经验证正确。

分组书名的层级高于对话标题；条目只保留标题，不展示日期、消息数量或整段引文。查看全部在本组原地展开，不跳新页；展开收起连续过渡、箭头同步变化，并遵循系统减少动态效果设置。轻点条目打开对话，左滑显示重命名、删除，不再叠加长按操作菜单；点击已展开操作的条目先收起操作。重命名时输入标题，删除时确认；读屏通过自定义操作访问两项。左滑手势复用成熟组件，动作样式与列表的间距、圆角和文字层级保持一致。

| 窗口或执行操作             | 必须保留的语义                                                             |
| -------------------------- | -------------------------------------------------------------------------- |
| 上拉弹层进入专注、下拉收回 | 由成熟组件吸附到两档，连续动效；不重建会话、不清空输入、不重启回答。       |
| 收起或关闭问答             | 返回阅读并保留阅读位置；不等于取消生成，重开仍连接同一对话状态。           |
| 明确停止                   | 取消当前生成与工具工作；已有内容按真实未完成状态保留。                     |
| 系统中断、断网或进程终止   | 不把未完成标成成功；保留已收到并保存的内容，提供实际支持的重试路径。       |
| 长时间后台                 | 不承诺系统给予固定运行时长，也不承诺强杀后继续完成；重试不冒充原任务接续。 |

问答输入的保留与笔记编辑器的关闭丢弃是两条不同规则。assistant-ui 负责通用聊天展示，书灯负责选文、书籍绑定、来源、保存与生命周期；工程合同见[阅读 Agent](architecture/reading-agent.md)。

## 我的与设置

“我的”是个人阅读模块，设置属于其中一部分；顶层继续保留书架、对话、我的。当前入口较少，在“我的”同页组织 AI 与助手及通用设置，不新增只负责中转的“设置”页面。“通用”按真实已有内容分组，不为凑分组增加功能或说明文案。

阅读报告、个人阅读回顾属于未来可考虑的方向，尚未进入本阶段功能范围。具备真实功能和数据后再决定首页的内容及设置入口位置；目前不展示未实现入口、虚构统计或占位卡片，也不由本次整理新增数据采集。

下表定义当前内容归属与命名。此布局已接入开发包的真实服务、指令与资料流程；设备验收和仍未验证的边界见[设置接线记录](validation/2026-11-10/settings-integration.md)，不代表已经发布。

| 归属 | 名称 | 职责与边界 |
| --- | --- | --- |
| 我的 → AI 与助手 | AI 服务 | 管理及选择连接配置。一套服务包含名称、地址、密钥与模型，不能把整套配置仅称为“模型”；联网开关跟随具体服务。 |
| 我的 → AI 与助手 | 助手指令 | 编辑全局人设、语气与回答偏好，沿用既有保存和下一轮生效规则。 |
| 我的 → AI 与助手 | 离线语义资料 | 下载、取消、重试和删除检索所需资料。资料已下载与各书索引已准备分开表达；书内原文搜索仍在阅读器。 |
| 我的 → 通用 | 关于书灯 | 版本、隐私政策与第三方许可。 |

AI 服务的接口格式在创建时确定；已保存的服务不提供预设替换或格式切换，改用另一种接口须添加新服务。名称、地址、模型、密钥和上下文窗口继续可编辑。自定义服务在创建页选择接口格式；上下文窗口页只管理自动资料与手动值，不承载连接类型配置。

当前阶段不展示外部工具（MCP）入口，书内检索和模型内置联网已覆盖本阶段需求；已有 MCP 配置和凭据按兼容资料保留，不因隐藏入口清除。我的页也不单列“AI 发送说明”，数据去向和费用在配置服务时告知，聊天中仍可查看当前服务及发送范围。

“我的”不再展示重复的外观入口。旧应用外观偏好与兼容路由保留，不因隐藏入口删除既有数据；字号与阅读主题继续以书内为唯一操作入口。隐藏旧入口不扩展书内主题的作用范围。

## AI 设置、联网与告知

“我的”在“AI 与助手”分组管理 AI 服务、助手指令与本地语义资料。当前阶段不展示外部 MCP 或独立“AI 发送说明”入口。模型未配置不能阻断阅读，发送问题时再提示配置。用户提供并选择 AI 服务，书灯不代付模型费用。

保存或更换 AI 服务前说明问题、相关原文和必要对话将发给谁，以及可能费用；服务地址或服务商改变时重新确认。普通问答不逐次弹长说明，轻量入口可查当前服务和发送范围。首次阅读、本机进度、标注及离线回看不依赖 AI 同意，隐私政策在“我的 → 关于”可达，见 [ADR-0012](adr/0012-confirm-ai-send-scope-on-setup.md)。

联网采用模型服务商内置能力，每个服务的编辑页单独开启，默认关闭，下一轮提问生效；兼容接口名称不代表支持搜索。助手自定义指令统一作用于各书，允许 Markdown、预填默认模板并可恢复默认，下一轮生效，保存失败保留编辑内容。当前运行固定启动时配置，不因设置变化重发回答。具体能力识别、迁移及失败规则见[Agent 契约](architecture/reading-agent.md)。

上下文配置默认自动，展示 LangChain 模型资料及其局限；无法识别时明确使用保守默认值。允许按服务商资料手填精确 Token 数或 K/M 简写，包括超过 100 万的窗口，不限制为固定档位。用户填写的值是书灯的预算依据，不会扩展服务商实际能力；模型输入上限、输出上限和共享窗口不能混为一个值，自定义地址的同名模型资料也不能当作该地址已验证的能力。解析、资料回退与预算合同见[Agent 契约](architecture/reading-agent.md#上下文与资源预算)。删除服务配置保留既有对话，删除当前服务后要求重新选择，不自动切换接收方。

离线语义资料按需下载，提供取消、重试与删除；未准备好或下载失败时说明语义检索不可用，阅读、原文搜索、标注、书签与 PDF 阅读仍可使用。资料完成后继续准备需要的书内索引，不用虚假“已准备”掩盖失败。

## 本机数据与兼容

书籍、阅读进度、标注、问答与原文关联须可靠保存，保存失败真实可见。移除书籍默认保留记录，彻底删除需明确确认；原文不可用时说明定位限制，不用同名书或重复文字静默替代。RN 保留本项目 Swift 数据的迁移兼容，迁移可重试、失败可诊断；旧数据只读与技术保护见[架构](architecture.md)。

## 当前阶段范围之外

- 跨书/全书架问答、无书籍通用聊天、OCR、朗读、独立翻译与阅读统计。
- 账号、云同步、完整备份恢复、协调 AI 服务器、代付模型和收费模式。
- ReadAny 的代码、提示词、资源或数据迁移；独立实现及品牌资源例外见 [ADR-0001](adr/0001-independent-implementation.md)。

## 行为核查示例

| 场景               | 操作与预期                                       | 不应发生                                 |
| ------------------ | ------------------------------------------------ | ---------------------------------------- |
| 未配置模型         | 导入、阅读、标注照常可用；发送问题才提示配置。   | 在进入书架或阅读前强制 AI 配置。         |
| 已有笔记、清空正文 | 保存不可用；关闭按既定规则丢弃未保存修改。       | 变成高亮或恢复已经取消的自动草稿。       |
| 回答正在生成       | 展开、收起、关闭再重开，保留同一会话与执行状态。 | 重复请求、丢输入或关闭即停止。           |
| 原文文件已移除     | 历史仍可回看，定位失败说明原文不可用。           | 跳到另一同名书，或把空页面当定位成功。   |
| 中断后返回         | 已保存内容标明未完成，按实际能力重试。           | 将残缺回答标为完成或宣称无条件后台恢复。 |
