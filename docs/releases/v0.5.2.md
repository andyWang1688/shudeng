# 书灯 v0.5.2

版本 0.5.2，构建 15。适用于 Apple Silicon Mac 上的 arm64 iOS 模拟器。

- EPUB 问答引用可点箭头或「返回问答」文字回到原对话。恢复原文位置失败时保留问答并给出提示。
- 半屏问答支持上下滚动历史消息；输入框支持换行和随内容增高；修正 iOS 对话首页首行书名显示。
- 回答正文不再显示异常引用字段，空引用不会吞掉正文；达到查书步数上限时显示中文提示。
- EPUB 长目录和 PDF 页面列表在半屏即可滑到末项，手柄仍可调整面板高度。

[下载与安装说明](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.2)。已有同包名版本可直接覆盖，无需先卸载。ZIP 不能安装到 iPhone。
