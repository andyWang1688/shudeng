# 书灯 v0.4.7

发布日期：2026-11-01。应用版本 `0.4.7`，构建号 `11`。

这一版补齐上下文管理：按模型窗口计算用量、只在接近上限时自动压缩、摘要跨轮保存，并在问答输入区显示用量圆环。

## 这次更新

### 上下文管理（DSH/Codex 风格）

- 按服务的**上下文窗口**计算预算，不再固定 10k：OpenAI/DeepSeek 默认约 128k，Anthropic 默认约 200k，可在「AI 服务 → 高级设置 → 上下文窗口」手动填写。
- 默认在**约 80% 窗口**才触发压缩；低于阈值不摘要、不裁剪。
- 压缩顺序：先精简超大工具结果 → 摘要较早对话（保留最近约 16%）→ 再次评估；摘要失败降级为裁剪；仍超出时明确提示，不静默截断。
- 摘要按对话保存在本机，下一轮继续使用；删除对话时一并清理。
- 问答输入区新增 **上下文圆环 + 百分比**（参考 DSH/Codex）：点按可看已用/窗口、对话历史/书内资料/摘要/系统提示构成，以及是否刚自动整理。
- 修复：固定 system 规则此前只参与预算估算、没有真正发给模型。

### 修复

- SSE 空 `data:` 心跳（部分 OpenAI 兼容网关的 keep-alive）不再导致整次回答失败。
- Agent 工具循环：空心跳、分块 UTF-8、并行工具调用、工具超限、取消、断点续跑等 30 个对抗用例已覆盖。

## 已知边界

- token 用量是启发式估算，不是 provider 精确计费值；圆环用于相对提醒。
- 摘要使用同一模型，摘要失败会降级为裁剪；超长单轮问题仍可能无法完成。
- 外部 MCP 工具默认关闭，iOS 17+ 才显示；完整添加/发现/调用链仍需补验收。
- 免费 Apple ID 签名 7 天过期；真机需自行签名。
