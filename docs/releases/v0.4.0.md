# 书灯 v0.4.0

发布日期：2026-10-29。应用版本 `0.4.0`，构建号 `4`。

本版加入完整 PDF 支持：导入、阅读、书签、文字型 PDF 的高亮/笔记/搜索与书内 AI 问答。继续通过 GitHub 提供 iOS 模拟器包，适用于 Apple Silicon Mac 上的 Xcode Simulator。真机、TestFlight 与 App Store 分发尚未验证。

## 这次更新

### PDF 导入

- 支持从文件选择器导入 PDF；导入时完整检查哪些页面有可选文字，显示「正在检查这份 PDF…（X/Y）」与取消；大文件不阻塞界面。
- **没有问题的 PDF 静默导入，不弹任何提示**。
- 只有扫描页才出现纸白说明卡：
  - 扫描版：「这份 PDF 是扫描版。页面上的字是图片，目前还不能选字提问或高亮。阅读、缩放和加书签都可以正常使用。」按钮「取消 / 继续导入」。
  - 部分扫描页：「这份 PDF 有 X 页是扫描图片，这些页目前还不能选字提问或高亮；其余页面正常。」
- 加密或损坏的文件不导入并说明原因；扫描页不再把纯白尾页算作扫描页。
- 问题 PDF 在阅读器右上角保留「?」，点开可随时查看同一段说明；不会重复弹窗打扰。

### PDF 阅读

- 固定版面阅读：双指缩放、连续滚动 / 单页切换、页码与阅读进度、返回上次位置。
- 目录 / 书签面板：PDF 自带目录、页级书签（按页排序、显示页首摘要、滑动删除、点击跳页）、阅读器上沿书签丝带。
- 书架显示 PDF 首页封面；PDF 与 EPUB 混排，继续阅读与已读进度共用书架。

### PDF 标注、搜索与 AI

- 文字型 PDF 选中文字后：4 色高亮、写笔记、问 AI；点已有高亮可改色或取消高亮（直接删除，无二次确认）；点笔记直接打开编辑器。
- 笔记页显示 PDF 标注的「第 N 页」，点击直接打开 PDF 到该页；编辑、删除与 EPUB 笔记一致。
- PDF 书内搜索：目录面板新增「搜索」tab，结果显示「第 N 页 + 摘要」，点击跳页；扫描版明确提示「没有可搜索的文字」。
- 书内 AI 问答：阅读器页脚「问书灯」或选文「问 AI」；回答引用显示「第 X 页 + 原文」，点击引用回到 PDF 对应页；对话历史中同样可用。
- 扫描版 PDF 不提供文字高亮、搜索与问答（不做 OCR），但仍可阅读、缩放和加书签。

### 质量与性能

- PDF 文字抽取与导入检查放到后台串行队列，逐页结束自动释放；进度按 1% 节流，取消可及时停止。
- 4000 页扫描 PDF 导入实测 **4.3 秒**（峰值约 329 MB），与不含空白页检测的基线持平。
- 翻页进度写入 0.7 秒防抖，退出阅读器立即落盘；从笔记或 AI 引用跳转 PDF 不再改写原阅读进度。
- 导入期间禁用底部 tab，切换 tab 不会卡住导入；进度浮层与扫描提示卡都从窗口顶层展示。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.4.0) 提供：

- `Shudeng-v0.4.0-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`。
- `SHA256SUMS.txt`：附件校验值。
- `release-manifest.json`：源码提交、工具链、应用哈希与验收范围。
- `INSTALL.md`：安装说明的离线副本。

需要 macOS、Xcode 与 iOS Simulator。最低构建设置为 iOS 16.0，本版只在 Apple Silicon 的 iOS 26.5 模拟器上验证；附件只含 arm64。

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.4.0-ios-simulator.zip .
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

更新请直接覆盖安装；卸载会删除本机数据，本版不提供完整备份与恢复。旧版本的 EPUB 书库、阅读进度、笔记与书签可直接升级，无需迁移。

## 已知边界

- PDF 不重排、不还原表格结构；引用与搜索定位到「第 X 页 + 原文摘录」，不保证页内坐标高亮。
- 扫描版 PDF 不做 OCR；页面无文字时不能选字、搜索或问答。若整本 PDF 没有文字页，纯白尾页可能被计为扫描页，但提示仍为「扫描版」，不影响阅读与书签。
- PDF 笔记创建后暂不支持在阅读器内改色（高亮可以改色）；可在编辑器中修改正文或删除。
- AI 问答仍使用当前书本地检索与一次生成，可能漏掉背景或给出错误结论；问题、相关原文和必要对话历史会发送到所选 AI 服务。
- 不提供 PDF 转 EPUB、扫描件 OCR、跨书问答、完整备份恢复或云同步；卸载或设备丢失后不承诺恢复记录。
- 真机、最低系统版本与商店分发仍未验证。
