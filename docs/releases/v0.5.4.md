# 书灯 v0.5.4

版本 0.5.4，构建 17。适用于 Apple Silicon Mac 上的 arm64 iOS 模拟器。

- 修复 iOS 后台回收阅读器 WebKit 进程后，回到书灯仍显示“阅读器已被系统回收”的问题。
- 回到前台会自动恢复当前书、最后阅读位置、阅读设置和标注；恢复期间显示加载状态。
- 自动恢复有自己的失败边界：恢复任务再次被系统终止时停止重试循环，并显示可重新打开的完整错误页。

已有同包名版本可直接覆盖安装。ZIP 适用于 iOS 模拟器。[下载与安装说明](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.4)
