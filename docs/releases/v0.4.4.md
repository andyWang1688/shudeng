# 书灯 v0.4.4

发布日期：2026-10-31。应用版本 `0.4.4`，构建号 `8`。

这一版只优化离线语义资料的下载：优先走国内加速线路，失败自动回退，下载从数分钟降到约 7 秒。

## 这次更新

### 离线语义资料下载加速

- 下载三份资料时优先使用国内加速线路，失败或校验不通过会自动切换到下一条线路，最后回退 GitHub 直连。
- 每条线路下载后仍做完整 SHA256 校验，校验强度不变；安装、取消、重试、删除、断点清理逻辑不变。
- QA 在模拟器实测：完整下载 **6.98 秒**，取消后重试 **6.36 秒**（此前 GitHub 直连 223–584 秒，受网络影响）。
- AI 设置里的说明新增「优先使用国内加速线路，失败自动切换。」
- 下载源只用于公开的模型文件，不涉及用户书籍、问答或 API Key。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.4.4) 提供：

- `Shudeng-v0.4.4-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`（不含离线语义资料）。
- `SHA256SUMS.txt`、`release-manifest.json`、`INSTALL.md`。

需要 macOS、Xcode 与 iOS Simulator。最低构建设置为 iOS 16.0；真机需要用自己的 Apple ID 签名安装，免费账号 7 天有效。附件是模拟器包，不含真机签名。

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.4.4-ios-simulator.zip .
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

更新请直接覆盖安装；旧版本书库、进度、笔记、书签、对话与已下载语义资料可直接升级。

## 已知边界

- 国内加速线路为第三方公开镜像，可用性可能变化；全部线路失败时回退 GitHub 直连，速度取决于网络。
- 首次 AI 语义检索仍需下载约 81MB 离线语义资料。
- 真机签名受 Apple ID 类型限制；免费账号 7 天过期。
- PDF 不重排、扫描版不做 OCR；大 PDF 滚动模式内存仍可能较高。
- 真机、iOS 16 与商店分发仍未验证。
