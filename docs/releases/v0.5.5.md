# 书灯 v0.5.5

版本 0.5.5，构建 18。适用于 Apple Silicon Mac 上的 arm64 iOS 模拟器。

- 优化中日韩 EPUB 排版。段距和段首缩进优先沿用书籍样式，缺少出版样式时使用 Readium 默认排版。
- 目录、书签、标注和阅读主题改用系统分段控件。长按封面或点书籍的更多操作，会打开 iOS 系统动作面板。
- 修复已经开启联网搜索时，问答仍可能提示没有联网工具的问题。答复会显示联网是否启用，网页引用仍取决于本轮是否实际搜索。

已有同包名版本可直接覆盖安装。[下载与安装说明](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.5)
