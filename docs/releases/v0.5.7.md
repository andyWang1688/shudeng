# 书灯 v0.5.7

版本 0.5.7，构建 20。适用于 Apple Silicon Mac 上的 arm64 iOS 模拟器。

- PDF 中文原句在排版换行处断开时，核实后仍可引用。点引用高亮原文，再点「返回问答」回到原会话。
- iOS 保存 AI 服务时使用输入框中当前的完整模型名，DeepSeek Flash 联网设置可在服务编辑页选择开启或关闭。
- DeepSeek 可在同一轮查书和读取指定网页。回答保留可核验的网页出处，并标明联网结果。网址后的英文逗号和句号不会随普通网址发给读网页工具。
- 模型传输中断或达到输出上限时，保留已返回的正文和重试入口。

已有同包名版本可直接覆盖安装。[下载与安装说明](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.7)
