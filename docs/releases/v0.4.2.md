# 书灯 v0.4.2

发布日期：2026-10-30。应用版本 `0.4.2`，构建号 `6`。

这一版是轻量化版本：安装包从约 133MB 降到约 32MB，本地 AI 语义资料改为首次使用时下载；大 PDF 默认单页，阅读内存和 CPU 明显下降。界面与 v0.4.1 一致。

## 这次更新

### 安装包瘦身与启动

- Release 打开 strip、关闭 testability：应用二进制从 53.1MB 降到 31.3MB（-41%）。
- 去掉每次启动重复准备、PDF 封面改为磁盘缓存、书架先出现再后台准备：书架可用时间从约 1.3 秒降到约 0.8 秒，启动峰值内存下降。
- Release app 约 **32MB**（不含需下载的离线语义资料）；v0.4.1 为约 133MB。

### 离线语义资料改为按需下载

- 「我的 → AI 服务」新增「离线语义资料」：显示未下载/下载中/已下载，支持下载、取消、重试和删除；下载约 **81MB**，逐文件 SHA256 校验后安装。
- 未下载时阅读、原文搜索、笔记、书签、PDF 阅读都不受影响；AI 语义检索会提示到 AI 服务下载资料。下载完成后会自动重试现有书的语义准备。
- Debug 与测试构建仍内置模型；Release 不再把模型打进安装包。

### 大 PDF 与内存

- **200 页及以上的 PDF 默认单页打开**，页脚仍可切换「单页 / 连续」；页数较少的 PDF 保持连续模式。
- 514 页 PDF 实测默认单页平均约 **339MB / CPU 19%**，连续模式约 **554MB / CPU 206%**；关闭阅读器后 footprint 可回落到约 39–53MB。
- PDF 文档改为异步打开（先显示「正在打开这本书…」），关闭时彻底释放 PDF 视图与文档；首帧约 0.7 秒可交互。
- 用户主动切回连续模式时，大 PDF 仍可能占用约 550MB；如需要更低的连续模式内存，需要后续自定义分页渲染。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.4.2) 提供：

- `Shudeng-v0.4.2-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`（不含离线语义资料）。
- `SHA256SUMS.txt`、`release-manifest.json`、`INSTALL.md`。
- 离线语义资料单独托管在 [semantic-model-v2](https://github.com/andyWang1688/shudeng/releases/tag/semantic-model-v2)，由 App 内「AI 服务」下载；引用/许可见该 release 的 manifest.json 与 LICENSE/NOTICE。

需要 macOS、Xcode 与 iOS Simulator。最低构建设置为 iOS 16.0，本版只在 Apple Silicon 的 iOS 26.5 模拟器上验证；附件只含 arm64。

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.4.2-ios-simulator.zip .
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

更新请直接覆盖安装；卸载会删除本机数据，本版不提供完整备份与恢复。旧版本的 EPUB/PDF 书库、进度、笔记、书签与对话可直接升级；升级后首次使用 AI 语义检索前需在 AI 服务中下载离线语义资料。

## 已知边界

- 首次 AI 语义检索需要联网下载约 81MB；下载失败时阅读、搜索、笔记仍可用，AI 语义检索需重试。
- 语义资料下载包 + 解压缓存占用约 200MB；删除模型后阅读不受影响。
- PDF 不重排、不还原表格结构；引用为页级；扫描版不做 OCR。
- 大 PDF 用户切回连续模式时内存仍较高；200 页阈值为经验值。
- AI 问答仍使用当前书本地检索与一次生成，可能漏掉背景或给出错误结论；问题、相关原文和必要对话历史会发送到所选 AI 服务。
