# 书灯 v0.2.0

发布日期：2026-10-27。应用版本 `0.2.0`，构建号 `2`。

本次沿用 GitHub 的 iOS 模拟器包分发，适用于 Apple Silicon Mac 上的 Xcode Simulator。真机、TestFlight 与 App Store 分发尚未验证。

## 这次更新

- 重做书架、笔记、对话与“我的”的界面层级，保留纸白、墨色和暖灯色；笔记与对话可按书折叠。
- 阅读正文始终铺满安全区域，工具栏覆盖淡入淡出；收起与恢复不再重新分页或转圈。修复仿真翻页后点按失效，保留旋转、取消翻页与重开后的原文位置。
- AI 设置提供 DeepSeek 预设、持续可见的字段名称及高级设置；保存或更换服务时确认发送内容、去向和费用，普通问答不再逐次弹窗。隐私政策可从“我的 → 关于”查看。
- 修复空问答草稿进入历史的问题；改进 API Key 缺失、锁定与鉴权失败的提示和重新填写入口，避免读取配置时清理其他配置仍使用的密钥。
- 移除“仅已读”与已读范围管理；问答现在始终可以参考当前整本书，包括未读章节。已有问答正文和引用保留。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.2.0) 提供：

- `Shudeng-v0.2.0-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`。
- `SHA256SUMS.txt`：附件校验值。
- `release-manifest.json`：对应源码提交、构建工具链、应用哈希和验收范围。
- `INSTALL.md`：安装说明的离线副本。

需要 macOS、Xcode 与 iOS Simulator；本版已验证 Apple Silicon 上的 iOS 26.5 模拟器。最低系统构建设置为 iOS 16.0，较早系统与 Intel Mac 未验证；本版附件只含 arm64。

下载所有附件到同一目录后执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.2.0-ios-simulator.zip .
xcrun simctl list devices booted
```

将下面的 UDID 替换为现有目标模拟器：

```sh
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

也可把 `Shudeng.app` 拖入已启动的模拟器。更新请直接覆盖安装；卸载会删除本机数据。本版没有完整备份与恢复功能。

旧 AI 配置首次用于发送时，可能需要到“我的 → AI 服务”确认发送说明；如明确提示密钥缺失，重新填写自己的 API Key 并保存。连接检查不会代替保存。

## 验证范围

阅读工具栏改动的定向 3 项及清理诊断代码后的 6 项回归通过，覆盖三种模式显隐、连续点按、隐藏后真实翻页或滚动、恢复后进入设置、浅深色选文与笔记、旋转、取消仿真翻页、关闭重开及引用返回。

在 SE3 / iOS 26.5 专用模拟器中，从应用收到点按回调开始，控件显隐约 210–232ms；新的正文 DOM 采样可用约 223–263ms。切换控件没有重建阅读器或进入加载。这是本次固定环境的结果，不代表所有设备的延迟保证。

AI 设置、发送确认、草稿、分组和密钥恢复的验证记录见 [#36](https://github.com/andyWang1688/shudeng/issues/36)、[#38](https://github.com/andyWang1688/shudeng/issues/38)、[#39](https://github.com/andyWang1688/shudeng/issues/39)、[#40](https://github.com/andyWang1688/shudeng/issues/40)、[#41](https://github.com/andyWang1688/shudeng/issues/41) 和 [#42](https://github.com/andyWang1688/shudeng/issues/42)。工具栏的实测与交付记录见 [#37](https://github.com/andyWang1688/shudeng/issues/37#issuecomment-6414890740)。旧 Key 的恢复通过用户重新填写完成，本版没有找回历史密钥。

本版在已验收源码上只更新版本信息后重新构建，发布包另做版本、签名、内容审计及启动检查。实际发布提交与包哈希见随附清单。此前真实服务的首发问答质量与后台证据保留在 [v0.1.0 说明](v0.1.0.md)，本轮未重跑真实 AI 回答质量测试，也未把旧结果标作新版重新验收。

## 已知边界

- AI 问答仍使用当前书的本地向量与关键词混合检索，最多 8 块材料、一次生成；可能漏掉背景或给出错误结论，重要内容应核查原文。
- 问题、相关原文和必要对话历史会发送给所选服务，由使用者承担费用；本地索引不等于问答完全离线，整书范围也不保证无剧透。
- 不保证系统允许后台固定运行 20–60 秒；中断后保留已保存内容并允许主动重试。
- 不提供 PDF、跨书问答、完整备份恢复或云同步；卸载、设备丢失后不承诺恢复记录。
- VoiceOver 与“减少动态效果”本轮只有代码核对，没有独立运行验收；最低 iOS、真机和商店分发未验证。
