# 书灯 v0.4.3

发布日期：2026-10-31。应用版本 `0.4.3`，构建号 `7`。

这一版修复真机启动闪退，并把 iPhone 安全区、横屏、大字号与 PDF 阅读方式统一到所有机型。

## 这次更新

### 真机启动

- 采用 UIScene 生命周期（`SceneDelegate` + scene manifest），修复 iOS 27 真机启动时 `UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption` 崩溃；模拟器与真机统一。
- 显式声明支持竖屏与左右横屏，不使用倒置竖屏。

### 全机型安全区与横屏

- 底部 tab bar 为 home indicator 留出安全区（56 + 底部 inset）；无 home indicator 的 iPhone SE 保持 56pt；按钮内容不再被系统横线遮挡。
- EPUB 阅读器正文与工具栏/底栏、PDF 阅读器工具栏/底栏/书签丝带在横屏下避开左右安全区；PDF 顶部安全区新增纸白背板，沉浸时页面可延伸到安全区。
- 问答面板、笔记编辑器在横屏与中文键盘下使用水平安全区，关闭/保存/输入框保持可见。
- Dynamic Type XXXL 下阅读器标题/章节、底栏进度与「问问书灯」、tab bar 文案不再裁切或重叠；阅读正文仍随系统字号放大。

### PDF 阅读方式与 EPUB 一致

- PDF 顶部工具栏新增「阅读设置」（ellipsis，与 EPUB 同位置），设置里只有 **分页 / 滚动** 两种方式（PDF 不做仿真翻页）。
- 「滚动」为纵向连续下滑；「分页」为左右单页。切换立即生效并保持当前页，按书保存选择。
- 页脚移除单独的模式按钮，只保留「问书灯 + 页码 + 进度」，与 EPUB 底栏一致。
- 默认仍保持：200 页及以上 PDF 单页，较小 PDF 滚动；用户手动选择会优先。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.4.3) 提供：

- `Shudeng-v0.4.3-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`（不含离线语义资料）。
- `SHA256SUMS.txt`、`release-manifest.json`、`INSTALL.md`。
- 离线语义资料仍由 App 内「AI 服务」按需下载（semantic-model-v2）。

需要 macOS、Xcode 与 iOS Simulator。最低构建设置为 iOS 16.0；真机需要用自己的 Apple ID 签名安装，免费账号 7 天有效。附件是模拟器包，不含真机签名。

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.4.3-ios-simulator.zip .
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

更新请直接覆盖安装；旧版本书库、进度、笔记、书签、对话与已下载语义资料可直接升级。

## 已知边界

- 真机签名受 Apple ID 类型限制；免费账号 7 天过期，需重新安装。
- 首次 AI 语义检索仍需下载约 81MB 离线语义资料。
- PDF 不重排、不还原表格结构；扫描版不做 OCR。
- 大 PDF 用户切到「滚动」模式后内存仍可能较高；想降低可继续用「分页」。
- 问答引用为页级；跨页长选文只标起始页。
- 真机、iOS 16 与商店分发仍未验证。
