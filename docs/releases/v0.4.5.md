# 书灯 v0.4.5

发布日期：2026-10-31。应用版本 `0.4.5`，构建号 `9`。

这一版只打磨阅读手感：书架封面不再闪、滚动阅读时快速拖一行不再误触工具栏。

## 这次更新

### 书架封面不再闪

- 资料准备进度、离线语义资料安装、导入新书等通知合并为一次刷新，不再频繁重建书架。
- 书目列表没有变化时只更新可见的状态/进度文字，**不重建列表、不清空封面**。
- 同一本书的封面与加载任务保留；导入新书只发生一次列表变化。
- QA 连续截图 156 帧（冷启动、模型下载完成、导入 4000 页扫描 PDF）确认既有封面没有空白帧。

### 滚动时不再误触工具栏

- 在 EPUB 与 PDF 阅读器增加拖拽识别：快速上/下拖动一行不再被当成轻点，不会触发工具栏隐藏/显示。
- 拖拽结束后 0.4 秒内的补发轻点也被忽略；静止轻点仍可正常显示/隐藏工具栏。
- QA 在 EPUB/PDF 滚动模式各做 10 次 12pt 快速上/下拖，工具栏未误切；翻页、选字、标注、书签、搜索、问答回归通过。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.4.5) 提供：

- `Shudeng-v0.4.5-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`（不含离线语义资料）。
- `SHA256SUMS.txt`、`release-manifest.json`、`INSTALL.md`。

需要 macOS、Xcode 与 iOS Simulator。最低构建设置为 iOS 16.0；真机需要用自己的 Apple ID 签名安装，免费账号 7 天有效。附件是模拟器包，不含真机签名。

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.4.5-ios-simulator.zip .
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

更新请直接覆盖安装；旧版本书库、进度、笔记、书签、对话与已下载语义资料可直接升级。

## 已知边界

- 拖拽保护对小于约 10pt 的快速微拖可能仍有残差，真实手感建议继续反馈。
- 首次 AI 语义检索仍需下载约 81MB 离线语义资料（优先国内加速线路）。
- 真机签名受 Apple ID 类型限制；免费账号 7 天过期。
- PDF 不重排、扫描版不做 OCR；大 PDF 滚动模式内存仍可能较高。
- 真机、iOS 16 与商店分发仍未验证。
