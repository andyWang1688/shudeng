# 书灯 v0.4.1

发布日期：2026-10-30。应用版本 `0.4.1`，构建号 `5`。

这是一次 PDF 阅读与问答体验的打磨版，同时修正了对话历史和「我的」页的两处界面问题。

## 这次更新

### PDF 沉浸阅读

- 阅读 PDF 时**单击页面即可隐藏顶部工具栏和底部页码栏**，再单击恢复；上下栏悬浮在书页之上，显示/隐藏时**页面位置和缩放完全不动**。
- PDF 阅读器打开后状态栏保持隐藏，减少干扰；书签丝带随工具栏一起隐藏/恢复。
- 点标注、选字、打开目录/问答/笔记编辑器时不会误触沉浸切换。

### PDF 选字

- 长按选字后保留 PDFKit 原生选区手柄，可以**拖动手柄扩展到多字、多行**，而不是只能选长按命中的两个字。
- 停止拖动约 0.25 秒后出现「高亮 / 写笔记 / 问 AI / 取消」纸白浮层，使用你最终选中的范围；再次调整选区时浮层会重新定位。

### PDF 书内 AI

- **跨段落、跨页的长选文现在可以正常提问**：校验不再只按单个片段匹配，会先把同页多段、必要时把整本书的文本拼接后核对。
- 回答成功后不再显示「回答已保存 / 部分出处未通过核验」这类系统状态，只保留回答正文、书内依据和「继续问书灯…」。
- 新建问题不再出现「问题草稿」状态条；失败、未完成、未保存等需要处理的状态仍会显示。
- 引用仍为页级定位（第 X 页 + 原文摘录），长选文跨页时只标起始页。

### 界面修正

- 书架搜索框空闲时不再一直显示圆形「X」（它原本是退出搜索，不是搜索按钮）；开始编辑时才出现取消按钮，取消/回车/收键盘后自动隐藏。
- 对话历史改名后列表**立即显示新标题**，重启后仍保持；之前改名其实已保存，只是列表 cell 没有刷新。
- 「我的」页去掉顶部「书灯」品牌大卡片，直接从「设置」「关于」两组系统列表开始；灯标、书灯、motto 与版本信息保留在「关于书灯」页。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.4.1) 提供：

- `Shudeng-v0.4.1-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`。
- `SHA256SUMS.txt`：附件校验值。
- `release-manifest.json`：源码提交、工具链、应用哈希与验收范围。
- `INSTALL.md`：安装说明的离线副本。

需要 macOS、Xcode 与 iOS Simulator。最低构建设置为 iOS 16.0，本版只在 Apple Silicon 的 iOS 26.5 模拟器上验证；附件只含 arm64。

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.4.1-ios-simulator.zip .
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

更新请直接覆盖安装；卸载会删除本机数据，本版不提供完整备份与恢复。v0.4.0 的 EPUB/PDF 书库、阅读进度、笔记、书签与对话可直接升级，无需迁移。

## 已知边界

- PDF 不重排、不还原表格结构；引用到「第 X 页 + 原文摘录」，不保证页内坐标高亮；跨页长选文只标起始页。
- 扫描版 PDF 不做 OCR；页面无文字时不能选字、搜索或问答。
- PDF 笔记创建后暂不支持在阅读器内改色（高亮可以改色）；可在编辑器中修改正文或删除。
- AI 问答仍使用当前书本地检索与一次生成，可能漏掉背景或给出错误结论；问题、相关原文和必要对话历史会发送到所选 AI 服务。
- 不提供 PDF 转 EPUB、扫描件 OCR、跨书问答、完整备份恢复或云同步；卸载或设备丢失后不承诺恢复记录。
- 真机、最低系统版本与商店分发仍未验证。
