# 书灯 v0.1.0

发布日期：2026-10-22。首个 GitHub Release，应用版本 `0.1.0`，构建号 `1`。

**本次提供 iOS 模拟器应用包，不是 iPhone 安装包（IPA），也不是 TestFlight 或 App Store 发布。** 包内不包含 API Key、个人书库、问答记录或测试样书。

## 下载与安装

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.1.0) 附件：

- `Shudeng-v0.1.0-ios-simulator.zip`：Release 配置的 `Shudeng.app`，包含 arm64 / x86_64 架构。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
- `release-manifest.json`：源码提交、应用及包文件哈希、工具链和验收范围。
- `INSTALL.md`：本页安装说明及限制的离线副本。

需要 macOS、Xcode 与 iOS Simulator；已验证的是 Apple Silicon 上的 iOS 26.5 模拟器。构建最低系统设置为 iOS 16.0，但 iOS 16 和 Intel Mac 未实测。

下载附件到同一目录后校验并解压：

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.1.0-ios-simulator.zip .
xcrun simctl list devices booted
```

使用上一步中目标模拟器的 UDID 安装；保留现有设备，不必新建：

```sh
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

也可将 `Shudeng.app` 拖入已经打开的 iOS 模拟器。不要卸载原应用来更新，卸载会删除本机数据；本版本没有完整备份恢复功能。

首次使用需自行导入可重排 EPUB，并在“我的 → AI 服务”设置服务地址、模型和自己的 API Key。支持 OpenAI Chat Completions 与 Anthropic Messages 的非流式文字接口，格式兼容不等于所有模型扩展均受支持。问题、相关原文及必要历史会发送给选定服务，服务费用由使用者承担；本地索引不代表问答完全离线。

## 首版功能

- EPUB 导入、书架搜索/排序、继续阅读。
- 左右翻页、连续滚动、仿真翻页；目录、书内搜索、书签、字号和明暗主题。
- 高亮、笔记、对话历史与草稿的本机保存和原文定位。
- 选文提问、单书自由提问、同对话追问；本地向量与关键词混合检索，最多8块材料、一次最终生成。
- 明确确认的“仅已读”范围控制；多套 AI 配置与连接检查。
- 有限后台生成；系统中断时保留已保存内容、标明未完成并允许主动重试。

## 已知限制

- 检索可能漏掉必要背景，不能保证完整概括或理解整书。
- AI 偶尔把材料外背景误说成引用已经证实的事实；引用文字真实不等于结论正确，无依据题也可能附弱相关引用。重要结论应核查原文。
- “仅已读”限制实际发送的资源，但已读导读本身可能含后文信息，不保证完全无剧透。
- 不保证后台固定运行20～60秒；60秒受控请求曾因系统后台时间到期而中断，不能保证强杀或断网后完成。
- 不提供 PDF、跨书问答、完整备份恢复或云同步；卸载或设备丢失后不承诺恢复。
- 真机、最低iOS版本、正式发行签名、TestFlight 和 App Store 未验证。本包仅用于模拟器，不能改名为 IPA 后安装到手机。
