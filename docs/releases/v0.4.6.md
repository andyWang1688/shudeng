# 书灯 v0.4.6

发布日期：2026-11-01。应用版本 `0.4.6`，构建号 `10`。

这一版把阅读问答升级为**原生 Agent**：不再只做一次检索，而是可以在书内多步查证、读章节、核对引用，再给出带出处的回答；全程在本机运行，不需要服务器。

## 这次更新

### 原生 Agent（无服务器）

- 支持 OpenAI / Anthropic 原生 **tool calling** 与流式输出；模型不支持工具时自动回退原来的普通问答。
- 最多 8 步：查书 → 读页/章节 → 目录 → 笔记 → 当前阅读位置，再综合回答。
- 每次工具调用在回答上方显示为可展开的步骤，例如「查书内资料 · 『灯』」；默认收起，不打断阅读。
- 上下文管理：旧对话摘要、工具结果裁剪、材料预算与用量显示；超预算会明确提示，不再静默截断。
- 会话检查点：步骤、工具结果、回答、引用与摘要保存在本机；删除对话会清理对应检查点。
- 回答仍要求给出可核查的书内引用；PDF 页级引用继续支持点击跳回原文。

### 可选的外部工具（MCP）

- iOS 17 起可在「我的 → AI 服务 → 外部工具」添加远程 MCP 服务，发现工具、逐项白名单、首次调用确认。
- 外部工具默认关闭；只转发必要参数，不把书库/API Key 交给 MCP；失败只少工具，不影响书内问答。
- iOS 16 不显示入口。MCP 不支持本地进程/OAuth，仅远程 HTTP/SSE。

### 兼容与边界

- 阅读、PDF、标注、书签、笔记、搜索、对话历史均保持原行为。
- 无工具能力的服务自动回退单次 RAG；回退时会在回答处说明“已改用普通问答完成”。
- AI 仍由用户自己配置服务与 API Key，书灯不提供模型服务，也不需要服务器。

## 已知边界

- 手动触发工具调用需要模型支持 tool calling；不支持时回退普通问答。
- Agent 最多 8 步；复杂问题可能需要缩小范围或新建对话。
- MCP 仅支持远程 HTTP/SSE，外部工具默认关闭且需确认；不支持本地进程/OAuth。
- 引用会核对原文是否真实存在，但不保证 AI 的解释一定正确。
- 离线语义资料仍需下载（约 81MB，优先国内加速线路）。
- 免费 Apple ID 签名 7 天过期；真机需自行签名。
