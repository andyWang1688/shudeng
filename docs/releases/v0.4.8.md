# 书灯 v0.4.8

发布日期：2026-11-01。应用版本 `0.4.8`，构建号 `12`。

这一版把 Agent 的思考过程和回答排版做成接近 DeepSeek / 豆包的体验，并补上上下文管理的两个可见问题。

## 这次更新

### 真流式思考过程

- DeepSeek 请求开启原生思考：`thinking: enabled`，`reasoning_effort: high`；读取流式 `reasoning_content`。
- 工具循环会把每一轮 `reasoning_content` 回传给模型，避免 DeepSeek 带 tools 时第二轮失败。
- 思考预算提升到 16K，单次超时 180 秒，整轮 300 秒。
- 生成中自动展开「正在思考」，思考文字逐段流式出现；查书步骤合并进同一个过程容器。
- 完成后折叠为「已思考（用时 X 秒）」；手动展开后不再自动收起；历史回看保留思考与耗时。
- 取消显示「已停止思考」，失败显示「思考失败」。
- 没有原生 reasoning 的模型不显示思考区，**不再用「我先」这类提示词前言冒充思考**。

### 回答排版

- 提示词允许并鼓励 Markdown：小标题、短段落、列表、加粗。
- App 端渲染标题层级、列表和加粗，回答不再是一整块文字。
- 正文里的 `[E1]` 内部标记隐藏；引用仍通过下方已核对的原文按钮查看。

### 上下文管理可见性

- 旧对话/普通问答没有 usage 时，按当前服务窗口显示上下文圆环（从 0% 起），不再直接隐藏。
- 「上下文窗口」从手填数字改为下拉：自动 / 32K / 64K / 128K / 200K / 400K / 1M；旧数据统一限制到最多 1M。

## 已知边界

- 当前只有 DeepSeek（OpenAI 格式）开启真思考；OpenAI 官方 Chat Completions 不提供原始思考，Anthropic thinking 回传尚未接。
- DeepSeek 思考会变慢、变贵；思考历史会增大请求体。
- token 为启发式估算；上下文圆环用于相对提醒，不是计费值。
- 思考区流式更新仍依赖消息栈重建（0.15 秒节流），不是逐字原地动画。
- 免费 Apple ID 签名 7 天过期；真机需自行签名。
