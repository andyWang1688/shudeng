# 书灯 v0.5.8

版本 0.5.8，构建 21。适用于 Apple Silicon Mac 上的 arm64 iOS 模拟器。

- EPUB 从目录跳转后可点「返回原处」。书内搜索支持返回原关键词和结果位置，刚查看的结果会标记出来。
- iOS 回收 EPUB 阅读器后，重开恢复阅读位置与问答引用高亮。同一布局下保留滚动视口。
- 重开已保存的问答可以先读历史。追问时可使用同一段对话曾经核对的网页出处，关闭联网后也能追问这些记录。
- 拒绝外部工具调用后，问答可以用手头资料继续。保存 AI 服务时保留原有列表顺序。
- EPUB 阅读设置可一键恢复默认排版，保留当前阅读位置、主题和阅读方式。

已有同包名版本可直接覆盖安装。[下载与安装说明](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.8)
