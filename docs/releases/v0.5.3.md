# 书灯 v0.5.3

版本 0.5.3，构建 16。适用于 Apple Silicon Mac 上的 arm64 iOS 模拟器。

- 阅读问答由模型在本轮预算内决定何时结束查书。书内证据不足时，会尽量区分原文依据与补充解释或推断。
- 问答在切换到其他 App 后可继续生成至 iOS 分配的后台时间结束。时间用尽时，保留已收到的正文，标记为未完成。
- DeepSeek 官方 `deepseek-flash` 可开启联网搜索。回答里的引用可紧跟相关句子，点书内引用可跳回原文。
- 修复部分 EPUB 正文字号调不动的问题。字号、字距、行距统一使用加减按钮，正文即时重排，设置按书保存。

已有同包名版本可直接覆盖安装。ZIP 适用于 iOS 模拟器。[下载与安装说明](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.3)
