# 书灯 v0.5.0

应用版本 `0.5.0`，构建号 `13`。本版将已确认的新界面接入 React Native/Expo 产品路径；正式 RN 包为 `dev.shudeng.mobile`。

## 这次更新

- **阅读与界面**：顶层为书架、对话、我的；EPUB 支持分页、仿真和连续跨章滚动，PDF 保留原生页面阅读。工具栏覆盖正文，目录、设置和问答弹层可向上展开。
- **书内标注**：高亮和笔记归入每本书，支持本书搜索、原文回跳、编辑、删除与导出；书架菜单可直接查看保留标注。移除独立笔记栏目和继续阅读卡片，阅读进度继续保存。
- **阅读问答**：设备内 LangChain/LangGraph 编排当前书的检索与原文读取，使用 assistant-ui 展示对话；可多次补查书内依据。支持的服务可单独开启内置联网，网页来源与书内引用分开。
- **我的与服务配置**：AI 服务、助手指令、离线语义资料、关于四个入口。iOS 服务表单和对话列表采用系统组件；接口格式在创建后固定，服务可删除，上下文可自动识别或手填 `1M` 等数值。

## 下载与数据边界

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.0) 的交付文件为 `Shudeng-v0.5.0-ios-simulator.zip`、`SHA256SUMS.txt`、`release-manifest.json` 和 `INSTALL.md`。ZIP 内为 `Shudeng.app`，仅供 Apple Silicon Mac 的 arm64 iOS 模拟器使用，不是真机、TestFlight 或 App Store 发行。最低构建目标 iOS 16.4，不等于已完成该系统的运行验收。

本版与旧 Swift 包 `dev.shudeng.app`、Small 开发包 `dev.shudeng.integration` 的沙盒独立；不会覆盖或自动迁移其中的书籍、记录和密钥。保留旧包，向新版重新导入需要阅读的文件；没有跨包一键迁移或完整备份恢复。

## 已知边界

- 大书长时间连续滚动仍存在已读文档增长及偶发长帧，巨型 spine 的精确章节标题也有限制；不承诺已完成大书内存和全场景流畅度验收。
- 无 OCR、固定版式 EPUB、跨书架问答、账号与云同步。扫描 PDF 页只提供阅读、缩放和书签。
- 真实服务商请求质量、搜索能力、计费、新凭据流程及完整 VoiceOver／大字体／深色组合未全面验收；自动模型资料可能过期，手动窗口不能扩大服务商限制。
- 本次不宣称真机、旧系统或其他平台兼容通过。API Key 与用户数据不随安装包分发；离线语义资料由用户主动下载。
