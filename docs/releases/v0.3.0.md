# 书灯 v0.3.0

发布日期：2026-10-29。应用版本 `0.3.0`，构建号 `3`。

本版继续通过 GitHub 提供 iOS 模拟器包，适用于 Apple Silicon Mac 上的 Xcode Simulator。真机、TestFlight 与 App Store 分发尚未验证。

## 这次更新

### 界面：优先使用系统组件

- 笔记与对话历史迁移到 `UICollectionView` 列表 + diffable section snapshots + 系统展开指示器；笔记页合并为一个「笔记」列表（高亮 + 笔记），按书分组、组内按阅读位置排序。
- 「我的 / 关于书灯 / 第三方许可」「AI 设置」「阅读设置」「阅读器目录与书签」改用系统列表与系统 accessory；AI 设置使用 `UIListContentConfiguration`，当前服务用系统勾选标记。
- 书架搜索改用系统 `UISearchBar`；列表行、空状态、进度条、滑动删除等尽量使用系统组件。纸白、墨色与暖灯令牌保持。

### 标注：高亮 / 笔记 / 书签

- 高亮支持 **黄 / 青瓷 / 雾蓝 / 胭脂** 4 色；选文后点「高亮」立即上色，底部轻量调色条可改色并自动收起。
- 笔记在原文中显示为**波浪线**；点波浪线直接打开编辑弹层（引用原文 + 正文），不再有中间「查看笔记」层。
- 笔记编辑改为可拖动的底部纸白卡片：初始 54% 屏高，键盘只上移并收窄、不自动升到整页；用户可拖动展开到 92%；关闭即丢弃未保存内容；**不再有草稿**，空正文不可保存。
- 不允许高亮与笔记互相隐式转换：高亮浮层无「写笔记」，笔记正文为空时保存禁用；要换类型先取消/删除再重新选文。
- 笔记可在编辑弹层中删除（红色「删除笔记」+ 确认）；删除高亮直接执行、不再二次确认；调色盘选色自动关闭。
- 阅读页右上角书签丝带；「目录 / 书签」面板中的书签行显示章节与阅读进度。

### 阅读器

- 修复 iOS 26 上「搜索取消后顶部大标题消失」与自定义导航栏外观遮挡大标题的问题。
- 去掉进入书时底部的「正在打开…」米色提示条（错误提示与重试保留）；「问问书灯」按钮缩小到 36pt、阴影减淡，命中区仍 ≥44pt。
- 修正笔记列表、书签匹配、Dynamic Type 与若干无障碍细节。

## 下载与更新

[GitHub Release](https://github.com/andyWang1688/shudeng/releases/tag/v0.3.0) 提供：

- `Shudeng-v0.3.0-ios-simulator.zip`：Release 配置的 arm64 `Shudeng.app`。
- `SHA256SUMS.txt`：附件校验值。
- `release-manifest.json`：源码提交、工具链、应用哈希与验收范围。
- `INSTALL.md`：安装说明的离线副本。

需要 macOS、Xcode 与 iOS Simulator。最低构建设置为 iOS 16.0，本版只在 Apple Silicon 的 iOS 26.5 模拟器上验证；附件只含 arm64。

```sh
shasum -a 256 -c SHA256SUMS.txt
ditto -x -k Shudeng-v0.3.0-ios-simulator.zip .
xcrun simctl install <模拟器UDID> ./Shudeng.app
xcrun simctl launch <模拟器UDID> dev.shudeng.app
```

更新请直接覆盖安装；卸载会删除本机数据，本版不提供完整备份与恢复。

## 已知边界

- AI 问答仍使用当前书本地检索与一次生成，可能漏掉背景或给出错误结论；问题、相关原文和必要对话历史会发送到所选 AI 服务。
- 不提供 PDF、跨书问答、完整备份恢复或云同步；卸载或设备丢失后不承诺恢复记录。
- 跨书查找书签需要先打开对应书；笔记页不包含书签搜索。
- 波浪线样式为自定义 decoration 模板（未改 Vendored Readium），极端字体/行高下可能略有差异。
- 真机、最低系统版本与商店分发仍未验证。
