# 书灯 v0.5.1

应用版本 `0.5.1`，构建号 `14`，应用身份继续为 `dev.shudeng.mobile`。

## 更新

- 修复已有对话因 AI 配置异常而无法回看的问题。未确认新版发送范围、配置读取失败时，仍能打开本机已保存的历史；发送和模型重试时提示具体配置问题并保留输入，仍须完成配置才能发出请求。
- 开发构建支持指定真机与团队签名；真机、模拟器分别保留最新产物，减少反复构建产生的磁盘占用。此项不改变公开安装包的分发平台。

## 安装与数据

[下载 v0.5.1](https://github.com/andyWang1688/shudeng/releases/tag/v0.5.1)。附件为 `Shudeng-v0.5.1-ios-simulator.zip`、`SHA256SUMS.txt`、`release-manifest.json` 和 `INSTALL.md`。ZIP 仅用于 Apple Silicon Mac 上的 arm64 iOS 模拟器，不能直接安装到 iPhone，也不是 TestFlight 或 App Store 版本。

已有 v0.5.0 同包名安装可直接覆盖，保留其本机数据；请勿先卸载。旧 Swift 版 `dev.shudeng.app` 和开发包 `dev.shudeng.integration` 仍为独立沙盒，没有新增跨包自动迁移入口。本次针对个人设备的一次性迁移记录不代表公开包具备自动迁移功能。

## 验证与限制

本次使用 v0.5.0 正式模拟器包的原生部分，重新生成 Hermes JS、更新版本和许可后重新签名；原生业务源码与依赖未改变。原生部分的编译工具链沿用 v0.5.0，重新打包及运行使用 Xcode 27.2。可核查结果见[本版验收](../validation/2026-11-18/release-v0.5.1.md)，安装包哈希及源码身份见随包 manifest。

真机开发安装曾验证历史回看和旧 PDF 高亮显示，范围见[迁移验收](../validation/2026-11-17/ios-usb-migration.md)；它与公开模拟器包分别记录。真实服务商请求、搜索质量、计费、完整手势与引用回跳、完整辅助功能和大书长时间滚动未在本版全面验收。其他功能与已知限制沿用 [v0.5.0](v0.5.0.md)。

第三方许可在「我的 → 关于书灯」可查。包内不含用户书籍、数据库、对话或 API Key，离线语义资料仍按需下载。项目自身许可证尚未选定，公开源码不等于授予开源许可。
