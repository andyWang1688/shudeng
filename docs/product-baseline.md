# 聊天决定与产品验收基准

本清单把本次重构聊天中的最终决定映射为可执行验收项，供实现、复审和交接使用。行为细节仍由[产品规范](product-scope.md)、[架构](architecture.md)、[界面规范](design/ui-development-standard.md)与[阅读 Agent 契约](architecture/reading-agent.md)各自维护；发现冲突须核对本页来源并同步正文，不能以已有代码或助手自报完成取代用户决定。

来源为「重构 iOS 到新 RN 架构」会话 `01a1a06c-1e7b-7ed0-8309-a7ee06bddd6c`。初次基准覆盖 2026-11-03 至 2026-11-08 当轮请求前的用户与助手消息；后续直接请求按日期追加来源。团队分段通读真实消息，跳过工具输出、推理与上下文压缩摘要；这些内容不作为新增需求。下方来源编号对应用户原话；助手实现说明只有在用户确认后才视为决定。截图用于辨认当时问题，不把整张旧界面自动定为永久要求。

## 使用与判定

按改动选择相关编号，在[验收记录](validation/README.md)写明输入、操作、实际结果和证据。每项分别记录源码检查、受控回归与设备实测：源码接线存在不能算设备通过，历史报告不能替代当前运行，未测、失败与已取代分别保留。整体达标要求当前生效项没有未解决失败，必要的设备和真实服务场景都有对应结果；测试条数不作为整体达标比例。

初次结果见[2026-11-08 基准复核](validation/2026-11-08/product-baseline-audit.md)；R05 的连续跨章实现与设备范围见[2026-11-09 验收](validation/2026-11-09/continuous-epub.md)，其中长时间阅读内存仍未通过。后续需求变化更新对应行为正文、本页取代关系与受影响用例，沿用编号，不把失效规则继续交给下一位 Agent。
