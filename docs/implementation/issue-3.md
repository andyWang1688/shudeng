# #3 阅读设置

- 沿用 UIKit / Readium 3.11.0；无依赖或生产资源修改。设置按书保存，首次为分页、100% 字号、明亮主题；字号 75%–200%，每次 25%。明暗主题显式覆盖系统外观，仅影响阅读及其设置页。
- 设置页为滚动表单，点击完成应用，取消或下拉关闭不应用。设置与该排版下的原生 Locator 写入同一书籍记录，经 library.json 原子写入成功后才发布内存状态；旧记录无设置字段按默认解码。
- 变更排版时从当前屏内第一可见字符取得临时元素范围、原文及前后文，交给 Readium 原有 text quote 定位；没有可见文字时保留原生资源比例。只用于此次切换，不把跨页段落起点写进日常存档；新导航器报告实际原生位置后同次保存设置与进度。主题单独变化也新建导航器，避免 Readium 相同位置不回调而遗漏设置保存。
- 加载中禁用再次设置和正文交互；成功、保存失败、原文加载失败分别显示。写入失败保留当前内存位置与设置，可重试；退出前明确提示未保存。重启恢复最后成功提交的一对位置和设置。
- 工具栏使用固定正文边界：隐藏书架及设置按钮时保留显示按钮及保存状态；显隐不遮盖正文、不触发重新分页。正文中部轻点或显隐按钮均可切换。辅助字体下短标题“设置”仍有完整无障碍名称“阅读设置”。
- 不实现目录、书签、卷页、AI 或高级排版。测试报告与运行截图见本地 `.scratch/delivery/issue-3.md`；真机、长书及广泛 EPUB 兼容性未验证。
