# #5 仿真翻页与选文共存

- 阅读设置增加“仿真”；按书与原生 Locator 一起原子保存。旧 ReadingSettings 缺少可选 pageCurl 字段时仍按原分页／滚动设置恢复。不改变书籍身份、书签和原文关联格式。
- 独立 UIKit UIPageViewController(.pageCurl) 控制翻页；停稳页承载真正的 Readium 正文，支持系统长按选文／复制，相邻页只用快照。最多缓存8页及实测前后关系。
- 最小 Readium 扩展 nativePaginationEnabled 仅控制外层分页、已加载及新加载 WebKit 滚动，保持程序导航及选文。非 upstream API，固定3.11.0；升级须复核三处。保留许可声明和旧字体排除，见 Vendor/Readium/README.md。
- 内部预取、恢复和 UIKit 转场期间隔离位置回调与持久化。go 完成并收到方向／资源／比例匹配的位置回调后才采用页面；恢复还核对首可见元素，失败不宣称就绪。取消不导航、不写进度；用户翻页停稳并准备完邻页后才保存实际原生 Locator，中途离场保留此前已提交位置。
- Readium 3.11 滚动结束通知有0.3秒去抖：提前到来的位置事件不能作为下一次反向导航已可安全开始的信号，否则相反滚动可抵消待发事件。已确认到达后串行等待350ms并再次核验；初始化和外部跳转也等待原生报告完成，避免读取仍带目标 fragment 的临时位置。8秒仅为失败看门狗，不作为渲染成功依据。
- 字号、主题和模式变化替换导航器；目录／书签跳转先销毁缓存，按 #4 核验目标后重建；正文尺寸变化（旋转、外围辅助字号布局）重建导航器与邻页。正文内链接引起新原生位置也重建。工具栏显隐保留原正文边界。
- 旋转先停止旧适配，在 UIKit 转场完成后重排，期间不接受旧位置保存。仿真模式保留重试行占位，保存状态至少两行；防止错误提示改变正文高度，引发缓存反复失效。
- 准备阶段暂禁设置与目录，书架仍可离开；离场先设置终止标志、解除代理、停止适配，晚回调不能重新创建卷页器。取消等待和未开始的内部导航不再执行，已进行的 Readium 操作无保存入口。
- 准备失败明确提示，可重试或改用普通分页；从用户待保存位置重新创建导航器，不保存临时邻页。原有文件加载失败、原子写失败和重试保留。
- 故障样书由 scripts/create-curl-failure-fixture.rb 从原创样书生成，首章声明 scripted 并拦截 scrollBy：程序翻页受理但没有新位置事件，触发真实准备失败看门狗；系统原生滑动仍可恢复阅读。只在测试 EPUB 内注入，不增加产品故障开关。

原创样书、正式用户操作及截图／落盘证据见本地 .scratch/delivery/issue-5.md。探针界面、诊断按钮和禁用外部导航的限制未带入产品，未复制 ReadAny 材料。真机、iOS16、长书性能、复杂CSS／RTL／竖排和内存压力未验证；模拟器证据不代表整项产品验收。
