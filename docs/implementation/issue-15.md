# #15 书架查找与基础排序

- UIKit 原生网格：普通字号两列，辅助字号一列自适应高度；保留导入、准备状态和按书续读。
- 本机书名或作者子串匹配，忽略大小写，去除查询首尾空白；空查询显示全部。无匹配与未导入分别提示，不调用书内检索或网络。
- 默认“导入顺序”：沿用 library.json 的追加次序，最早导入在前。“书名”：`localizedStandardCompare` 升序（当前系统语言的自然排序），比较相同时按书籍 ID 字符串升序。固定语言下同键次序稳定，切语言可改变书名次序。排序为本次书架会话状态，重启回导入顺序；清空搜索保留所选排序。
- 显示列表与原始书库分离；点选先取显示项 ID，再获取书库当前 Book。沿用 `open`、阅读器 `location(for: book.id)`、原有按 ID 保存位置，不新增时间字段、不重排或改写书库。
- 修改边界：App.swift 的书架及卡片、LibraryTests 排序搜索用例、ReadingUITests 网格定位与本票验证。本票不改变 #11 检索逻辑、阅读器或存储格式。
- 固定验证输入：既有原创 A=reflowable、B=same-title-distinct（同书名作者、不同 SHA）及 C=search-fixture（不同书名作者）；在 DEBUG `--isolated-reading-test` 目录内验证，保留原业务目录和 Keychain。
- 验证搜索 ID 集合、无结果与清空、两排序及同键稳定次序、A/B 独立位置重启恢复、普通两列与小屏最大辅助字号/深色实际操作。模拟器证据见 `.scratch/delivery/issue-15.md`；真机与最低系统版本未验证。
