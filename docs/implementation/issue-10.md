# #10 本地语义检索与混合取材

Base: `44727f10a919630921045ceca1f5f0acbe637cc2`。仅本地语义、混合取材与向量准备；不实现 #11—14。

## 固定输入、候选与预算（实测前）

- 原创样本：既有 fixture.json SHA256 `44550e12322be6ed9bb3cec39156c961203d18d7eed826c39f722c3d16aab9a5`；生成正式 EPUB，保留原 ID 和 Locator 对照。跨语言单独 EPUB 仅含 ch3-p2 英文答案及原80段中文干扰；不得带入中文同义答案。题目及必要依据沿独立 acceptance-plan，不删减。
- 候选：既有 MIT multilingual-e5-small 固定版本 `614241f622f53c4eeff9890bdc4f31cfecc418b3`（512 tokens，384维，既有跨语言失败）；Apache-2.0 sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 固定版本 `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`（128 tokens，384维，官方 ARM64 INT8 ONNX 约118MB）。MiniLM先与原始浮点/参考向量比较；不把ARM64产物当iPhone适配通过。不使用远端翻译或人工查询改写修补测试。
- 运行路线：成熟 ONNX Runtime iOS + Hugging Face Swift tokenizer，本地读取固定模型；平均池化与L2归一化，模型/tokenizer哈希和版本共同标记向量空间。长段按token限额拆分，不静默截断原文。
- 比较相同预算：词法/语义各前20；RRF常数60、等权，保留语义首位1个锚点，另4个来自RRF，5个锚点各补同章前后1段。强制选文及邻文优先；合计至多15段，沿 #9 最终prompt不超过24,000 UTF-8 bytes（取材预留23,000）；强制材料自身超限拒绝发送。记录实际候选、扩展来源、预算裁剪与缺失必要依据。
- 长书：Jane Austen《Pride and Prejudice》，Project Gutenberg #1342，作者1817年逝世，公开领域正文；取固定下载SHA的合法EPUB，保留来源与原许可。不用重复段落冒充真实长书；预期约12万英文词、61章，实际规模入库后如实记录。
- 初始工程预算（估计/验收目标，非手机实测）：模型资源含tokenizer不超过150MB；常驻推理并准备峰值RSS不超过600MB；单书约10,000块向量扫描+查询嵌入p95不超过2s；冷加载不超过5s；长书首次向量准备不超过15min、续做不重算已提交块；同时阅读主线程无持续100ms以上索引任务。模拟器报告实际值，真机时延/内存/发热耗电由 #18/#19复核，不降低门槛迎合结果。

## 必须验证

同义、英问中、唯一英依据+80干扰、三段跨章必要依据、强制选文邻文、范围过滤、另一书隔离；正式iOS真实模型与SQLite向量；实际提交后中断/写失败与恢复、模型不可用仍可阅读、重建不改业务文件。最终选择和实测证据完成后追加。

## 范围与局部路径

显式scope同时约束强制选文/邻文、候选和扩展；强制材料位置不在当前书允许范围则拒绝发送。实际发送context从quote重建，不发送Locator prefix/suffix或调用方自带context。local=true、scope=nil保留 #9 主动局部解释：来源为 ReaderController 从当前书 WebKit 真实可见DOM选区及邻接run捕获并保存在本书 ReadingQuestion 的材料，不依赖未准备完成的索引；它不接受模型产生的Locator，也不声明整书取证。提供显式scope时局部路径同样验证原文位置。

## 实施结论

采用固定 MiniLM 官方 ARM64 INT8 ONNX；E5 原候选的唯一英文依据仍为第81名，不以它交付。模型、tokenizer、配置改动、依赖版本/许可/完整哈希见 `ios/Shudeng/Resources/SemanticModel/manifest.json`，完整声明随应用的“第三方许可”分发。原模型118,412,398字节，加tokenizer约127.5MB；gzip模型75,546,406字节。`scripts/fetch-semantic-model.py` 可重现固定字节；已用缓存的上游原件完整校验打包结果。应用只读取本地资源，首次解压并校验模型SHA，不自动联网下载。

每个原片段按128 token窗口生成384维向量，所有子块和片段游标在同一SQLite事务提交；失败回滚，中断从已提交片段继续。向量版本变化或显式重建只清派生索引，不清阅读进度、笔记、草稿或问答。资料准备失败时仍可阅读和字面搜索；未完整准备需等待或主动选择原有局部解释路径。
