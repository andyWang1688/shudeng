# Triage labels

| 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 新问题，尚未判断如何处理 |
| needs-info | needs-info | 缺少信息，需要补充 |
| ready-for-agent | ready-for-agent | 范围清楚，可交给 AI 执行 |
| ready-for-human | ready-for-human | 需要人工判断或操作 |
| wontfix | wontfix | 已决定不处理 |

技能引用这些角色时，使用表中的实际标签。已有标签保留，只补充缺少的标签。
