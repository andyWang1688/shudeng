# Domain docs

布局：single-context。

- 术语：根目录 `GLOSSARY.md`。
- 架构决策：`docs/adr/`。
- 首发决策入口：`docs/first-release-decisions.md`。
- 产品范围：`docs/product-scope.md`。

开始探索或设计前，阅读术语表及与任务有关的 ADR；涉及首发范围时阅读决策入口和产品范围。
Issue、规格、代码中的概念沿用术语表。若方案与已接受 ADR 冲突，明确指出冲突并讨论是否取代原决策，不得静默覆盖。
文档不存在时可继续工作，由 domain-modeling 在需要时创建；不提前建立空白文档体系。
