# 正文保持满屏，阅读控件以覆盖层显隐

用户在实际使用中指出，点击隐藏工具栏会转圈等待，破坏连续阅读。2026-10-26 明确选择“正文始终满屏，工具栏覆盖并淡入淡出”，取代 ADR-0010 中显隐时扩大或缩小正文、触发重新分页的做法；阅读优先与渐进披露的其余原则不变。

正文始终使用整个安全区域。顶部工具栏、底部信息栏和问答入口覆盖在正文上，点击中部以约 200ms 的淡入淡出一起切换；正文位置、分页和卷页缓存不因显隐改变。显示控件时允许短暂覆盖边缘原文，读者再次点击即可完整阅读该处，不能额外预留永久空白。

工具栏显隐不触发阅读器重建、资料加载或翻页准备；隐藏终态不拦截触控和无障碍焦点，快速连续点击按最后一次意图收敛。减少动态效果时取消过渡；字体、主题、旋转等真实布局变化仍沿用原文位置恢复与缓存失效规则。规格与验收见[覆盖式阅读控件](../design/2026-10-26/reader-overlay-controls.md)，跟踪 [#37](https://github.com/andyWang1688/shudeng/issues/37)。
