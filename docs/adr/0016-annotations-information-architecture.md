# 将内容标注与位置书签分开

原先笔记页的高亮、笔记、书签三类筛选，以及阅读器中的重复入口，把内容理解与位置导航混在一起。决定将高亮和笔记合并为按书整理的标注列表，书签仅在阅读器管理；相比保留三分类和跨书书签入口，选择概念清晰、入口较少的组织方式，代价是跨书查书签需先打开对应书。

2026-11-07，[ADR-0021](0021-book-owned-annotations.md) 进一步将标注归入书内，取代全局笔记栏目的入口与分组安排；本记录的标注/书签区分和下述保存语义继续有效。

用户随后明确简化标注交互：高亮和笔记不隐式互转，点笔记原文直接编辑，笔记关闭丢弃未保存内容并取消自动草稿；这些选择的保存后果仍须保留，不能因通用聊天或设计规则而改变。详细行为维护在[产品规范](../product-scope.md#标注与书签)，各端容器遵循[界面规范](../design/ui-development-standard.md)。

完整迭代与旧 UIKit 细节保存在[历史记录](../archive/planning/0016-annotations-history.md)，不恢复其中已被后续决定取消的入口、草稿或卡片尺寸。
