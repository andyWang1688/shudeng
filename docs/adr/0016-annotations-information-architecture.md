# 标注的信息架构与呈现

## 背景

此前笔记页把「高亮 / 笔记 / 书签」做成三个并列筛选，阅读器目录面板又出现第四个「笔记」tab。用户指出三者不是同一层级的概念：书签是位置快捷入口，高亮与笔记是对原文的标注；并要求参考主流读书 App（Apple Books、Kindle、微信读书）与 ReadAny 的「书灯」原型。

## 决定

- **笔记页**：不再有筛选 tab，合并展示全部标注（高亮 + 笔记）；书签不在此页出现；按书分组、组内按阅读位置排序；行内以颜色点、引文、笔记正文与 2pt 左细线区分，不显示“高亮/笔记”分类标签；行点击跳回原文，左滑编辑（仅带正文的笔记）、右滑删除（确认）。
- **书签**：只在阅读器内管理。目录面板恢复「目录 / 书签」两个 tab；书签行显示章节与阅读进度，点击跳转，滑删保留；页面右上角丝带标记当前页书签。
- **阅读器呈现**：高亮 = 原文底色；笔记 = 波浪线。Readium 无原生波浪线，使用 App 侧自定义 `HTMLDecorationTemplate`（style id `note-wave`，平铺 SVG 背景）实现，不改 Vendor；decoration 签名包含 body/kind，正文状态变化时重绘。
- **点击分流**：点高亮 → 4 色改色 / 写笔记（主动升级为笔记）/ 取消高亮（确认），不自动弹编辑框；点波浪线 → 查看/编辑/删除笔记浮层（含下划线颜色）；笔记页行点击只跳原文。
- **搜索**：笔记页搜索覆盖书名、章节、引文与笔记正文；不含书签。

## 备选与取舍

- 保留三分类 tab：概念层级仍然混乱，且与“书签只在阅读器”的决定冲突，放弃。
- 书签继续留笔记页：对跨书书签更友好，但书签的语义是页内快速跳转，收益低于概念清晰度；未来如需要再加“全部书签”入口。
- 改 Vendor 增加 `.wavy`：约 15 行但污染依赖，放弃。

## 后果

- 概念清晰：标注（内容）与书签（位置）分离；高亮/笔记共用一个记录模型（`BookNote.body` 空/非空）。
- 跨书查找书签需先打开对应书；笔记页不再提供书签搜索。
- 波浪线样式与点击命中依赖自定义模板，需截图与 UI 测试覆盖；旧数据仍默认黄色。
- 样式参考 ReadAny 仓库 `andyWang1688/ReadAny`（分支 `feat/native-ios`）的「书灯」iOS 原型：分组列表、颜色点、引文、正文左细线、滑动编辑/删除。

## 追加决定（2026-10-28）

- **笔记编辑器改为紧凑纸白弹层**：`pageSheet` + `[.medium, .large]` detents，不再全屏跳转；顶部 关闭 × / 笔记 / 暖灯「保存笔记」，引用原文缩为纸深引用块，正文内联输入，底部草稿状态；键盘出现自动升 `.large`。
- **禁止隐式类型转换**：高亮浮层不再提供「写笔记」（不把高亮升级成笔记）；笔记编辑器在正文为空时禁用保存（不把笔记降级成高亮）。要换类型先取消/删除对应标注，再重新选文创建。
- **空正文保护**：空正文不写草稿、不覆盖已有草稿；保存按钮 disabled 并提示「写点什么再保存」。

## 追加决定 2（2026-10-28，简化交互）

参考 Apple HIG：[Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)（medium detent 用于渐进展示，grabber 由用户拖动扩展）、[Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts)（不要为常见、可撤销的操作弹 alert）、[Modality](https://developer.apple.com/design/human-interface-guidelines/modality)（模态任务保持简短、聚焦）。

- 去掉笔记草稿：不再自动保存/恢复草稿，不再显示草稿状态文案；关闭即丢弃未保存内容。
- 编辑器改为自定义底部卡片（overFullScreen + 纸白卡片 + dim + grabber）：初始 54% 屏高；键盘出现时卡片整体上移并收窄到键盘上方（保留顶部留白），**不自动变成 large**；用户可拖 grabber 展开到 92%，下拉关闭。
- 取消高亮不再二次确认，点击直接删除；调色盘点选颜色后自动关闭。
- 笔记详情：引用用 paperDeep 浅灰底块，正文为普通文本（无卡片/边框），保持“怎么写就怎么看”。
- 不允许高亮与笔记互相隐式转换：高亮浮层无「写笔记」，笔记正文为空时保存禁用。

## 追加决定 3（2026-10-28，进一步简化）

- **笔记不再有“下划线颜色”**：高亮保留 4 色；笔记波浪线固定为品牌暖灯色（`BookDesign.lampInk`），笔记列表色点固定 `lamp`。
- **点原文波浪线直接进入编辑弹层**，删除「查看笔记」中间层（NoteDetailController 及其标识全部移除）；笔记删除入口移到编辑弹层 header 的红色「删除笔记」（确认后删除）。
- **阅读器进入书时不再显示底部「正在打开…」等米色状态条**；非错误状态不显示，错误提示与重试保留；加载只靠中央 spinner。
- **「问问书灯」按钮缩小**：视觉高 36pt（金色图标 16、字号 12、更淡阴影），命中区仍 ≥44pt。
- 参考 HIG：状态反馈只用于需要行动的错误（[Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback)），可撤销/常见操作不用提示打断（[Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts)）。
