# 整书问答采用本地混合检索与原文引用

2026-10-20 已被 [ADR0007：简单本地 RAG](0007-simple-local-rag.md) 取代；下文保留为历史决策，不代表当前首发方案。

阅读问答采用“先查书，再根据原文回答”：选文及附近原文直接进入上下文，在当前书内用关键词和语义检索找背景，再补齐命中段落前后文，全书问题单独覆盖各章；无选文的单书提问共用这条路径。资料与向量保存在本地 SQLite，先按当前书比较向量，不引入专门向量数据库；必要原文交给读者配置的 OpenAI 或 Anthropic 格式服务回答，并保存可定位引用和对话。

这避免只解释孤立选文或把少量相似段落当全书结论，也避免要求读者另配嵌入服务；代价是本地索引准备、模型体积与手机性能需要验证。默认允许整书、仅已读选项约束实际取证范围；依据不足需说明。E5只是候选，具体模型未定；模型主动补查能力仍需评估，不作为所有兼容接口都支持的前提。见[设计](../reading-ai-design.md)与[实验](../../.scratch/first-release-decisions/issues/10-ai-validation.md)。
