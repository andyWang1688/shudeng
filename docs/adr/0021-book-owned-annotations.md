# 高亮与笔记归入每本书

独立笔记栏目需要先按书分组，再回到阅读上下文。用户决定取消该顶层目的地，将高亮与笔记放入书内目录弹层的标注分栏，并由书架书籍菜单提供捷径；取舍是降低导航与分组负担，同时放弃集中跨书搜索和回顾，已有记录继续保留，已移除书籍仍能查看和导出。

本决定取代 [ADR-0016](0016-annotations-information-architecture.md) 中全局按书整理的入口安排，保留其内容标注与位置书签区分、高亮与笔记不隐式转换、明确保存和关闭丢弃等语义。详细行为见[产品规范](../product-scope.md#标注与书签)。
