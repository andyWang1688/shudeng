# 首发阅读问答采用简单本地 RAG

本决策已被 [ADR0008：本地向量与关键词合并](0008-local-hybrid-retrieval.md) 取代；下方保留纯向量历史正文，其余约束由新决策沿用。

首发保留应用已内置的 multilingual MiniLM，选文提问、单书自由提问和追问共用“当前书向量检索 → 去重与容量限制 → 一次最终生成”。SQLite 保存原文、位置与向量；选文保留，必要追问历史仅作语境，不作为书内依据。默认参考整书，“仅已读”在本地限制实际检索与发送范围；引用回跳、可靠保存和[有限后台生成](0006-bounded-background-generation.md)边界继续有效。

章节内按段落、句子切块，正文目标约100 tokens（包含重叠），不是硬截断长度；仅末尾完整短句可重叠，最多20 tokens。每块由实际 tokenizer 验证包含 special tokens 不超过128，这是当前模型的硬上限，不依赖截断；超长句需继续分块并保留精确原文及 UTF-16 位置。统一向量 Top-K 默认8，最多8个检索块，去重后仍受现有最终材料总预算约束；目标块长与 Top-K 参数是可调整的实现细节。

不再固定携带邻文、关键词混排、AI 拆题、选文解析、追问改写或补查，也不逐章覆盖；不提供嵌入模型选择、下载或云端 embedding。这样收敛首发调用与取材流程，代价是相关依据可能漏检；依据不足时明确说明，不得把少量命中当成完整全书结论。“整书问答”仅表示允许从当前全书查找相关依据，不承诺完整概括全书。

本决策取代 [ADR0005](0005-book-question-answering.md)；用户本次收窄了 [#11](https://github.com/andyWang1688/shudeng/issues/11) 的全书概括范围，旧验收不因此转为通过。[#20](https://github.com/andyWang1688/shudeng/issues/20) 的补查失败仍为失败，历史研究与证据保留。新方案实施与验收见 [#21](https://github.com/andyWang1688/shudeng/issues/21)；决策确认不代表应用或发行已通过验收。
