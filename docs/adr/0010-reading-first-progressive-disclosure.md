# 界面以阅读优先和渐进披露为新基准

2026-10-25，用户在实际使用后指出当前界面整体仍偏乱，偏好类似 Apple 的简洁体验，尤其不能接受 AI 设置页常驻大段技术说明。因此以本决策取代 [ADR-0009](0009-native-ui-design-baseline.md)：保留纸白、墨色、暖灯色、真实书封和四栏结构，但不再把 2026-10-23 的 `standalone.html` 当作后续视觉验收基准。

新基准遵循四条规则：一页只承担一个主要任务；默认页面只显示完成该任务必需的内容；隐私、费用、协议和技术选项渐进披露；每个页面只有一个明确的主操作。AI 服务列表负责选择，配置页负责设置，详情页负责解释，不再把三者堆在同一屏。

阅读器收起控件时，顶部工具栏、底部信息栏和“问问书灯”入口全部隐藏，正文扩展到整个安全区域；再次点击阅读区中部恢复控件，并保持当前阅读位置。代价是忽略间距变化可能触发重新分页，因此必须用可见原文锚点定位并覆盖三种阅读模式。

2026-10-26 更新：上述阅读控件显隐方式由 [ADR-0013](0013-fixed-reading-viewport-overlay-controls.md)取代。用户实际体验后明确选择正文始终满屏、工具栏覆盖并淡入淡出；点击不再改变正文尺寸或重新分页。本决策其余信息层级原则继续有效。

这次变更改变已确认界面的信息层级，实施时必须重新制作设计基准并逐页验收；旧设计稿和验收记录只作为历史证据保留。新的执行范围见 [#34](https://github.com/andyWang1688/shudeng/issues/34)。
