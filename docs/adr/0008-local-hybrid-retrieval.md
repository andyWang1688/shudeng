# 首发阅读问答采用本地向量与关键词合并

2026-10-20 用户批准以本决策取代 [ADR0007](0007-simple-local-rag.md)：仅将纯向量检索改为本地混合检索，以补充词面命中；原决定的其他约束继续有效。保留 multilingual MiniLM，在同一 SQLite 的现有 FTS 上取得有界关键词候选，与向量候选按稳定原文块身份去重、合并排序；最终最多8块，仍受原最终材料总预算约束。选文、单书自由提问与追问共用这条路径；当前书／仅已读限制同时约束两路候选和实际发送，精确原文、UTF-16 位置、引用、可靠保存、有限后台与一次最终生成边界不变。普通原文 `search` 保留原行为。

此次变更只替代“纯向量、不关键词混排”的约束。不换模型、不新增模型选择或下载、云端 embedding、工具 agent、AI 改写／拆题／补查、固定邻文或逐章覆盖；模型失败仍按原错误规则处理，不静默降级为仅关键词。借鉴 ReadAny 的设计思路，不复制其代码、提示词或资源；候选数和合并排序参数属于实现细节。混合检索仍可能漏检，不能把少量命中当成完整全书结论；整书问答仍不承诺完整概括全书。

状态：2026-10-20 [#21 技术验收通过](https://github.com/andyWang1688/shudeng/issues/21)，见[分阶段证据](../../.scratch/supervision/local-hybrid/acceptance.md)。原题已找回事故段 `ch2-p1` 与定义段 `ch1-p2`，同义／跨语、去重、精确块命中、范围、Top8、原材料预算及两种接口格式下单次最终请求等回归通过；沿用此前未受本轮改动影响的分块、重建续建、保存和后台回归。原纯向量漏检、#11 旧验收及 #20 补查失败和证据保留；整应用、真实 AI 回答质量、真机和发行未因此通过验收。
