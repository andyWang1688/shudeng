# 语义资料按需下载，大 PDF 默认单页

旧 Swift 版本的内置语义模型和大 PDF 连续渲染带来较高包体与运行内存成本。决定 Release 不内置离线语义资料，改为可取消、重试与删除的按需下载；大 PDF 在没有读者偏好时默认单页，仍允许切换，以首次配置成本和连续浏览便利性换取更轻的下载与默认资源占用。

未准备语义资料时，阅读、原文搜索和标注仍可用，语义检索不可用须真实说明。当前用户行为与 PDF 默认规则维护在[产品规范](../product-scope.md)，实际下载校验及运行保护以平台实现和[架构](../architecture.md)为准；按需下载不代表模型可以混用，也不保证所有大文件内存已验收。

旧包体、内存采样、模型路径及构建细节保存在[历史记录](../archive/planning/0018-lightweight-model-history.md)，不作为 RN 或当前设备的测量结果。
