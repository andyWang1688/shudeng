# 首发保留本机可靠保存，完整备份移后

用户进一步确认完整备份功能不急于首发，因此以此决策替代 ADR-0002：保留阅读进度、笔记、问答的本机持久保存、保存失败处理与草稿恢复，将完整备份导出和恢复移后，首发也不做云同步。这样收窄了首发范围，但应用内异常恢复不等于卸载、设备损坏或丢失后的数据恢复。

后续 [ADR-0016](0016-annotations-information-architecture.md)明确取消笔记自动草稿，聊天输入与生成状态的保护继续保留。当前各任务的保存与关闭后果见[产品规范](../product-scope.md)，不把本条早期的“草稿恢复”泛化到所有编辑器。
