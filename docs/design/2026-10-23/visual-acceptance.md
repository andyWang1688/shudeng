## 固定设计夹具基线（Issue #24）

2026-10-23 已建立显式测试接缝：

- 启动参数 `--design-fixture=normal` 仅存在于 DEBUG 测试构建，生成隔离的临时 EPUB 书库、封面回退、笔记、书签、两组对话和仅内存 AI 配置；`empty` 生成空书架状态，`preparing` 生成可阅读但资料准备中的固定状态。
- 设计夹具使用内存密钥实现，不读取真实 Keychain；生产启动路径不读取夹具。
- 四栏保留稳定测试标识 `tab-library`、`tab-notes`、`tab-conversations`、`tab-profile`，后续自定义底栏必须继续提供同一接缝。
- 单元测试使用同一组真实 UIKit 页面控制器渲染 375 × 667 和 390 × 844、浅色和深色共 16 张固定尺寸截图；应用级测试在唯一 Shudeng Small 上覆盖四栏、阅读和问答入口。

当前证据保存在本机 `.scratch/test-evidence/issue24/final5.xcresult`：3 tests / 0 failures，包含 16 张固定尺寸渲染、7 张 Shudeng Small 应用级截图和夹具显式启用。应用级截图在 240ms 设计动效结束后取得，并按 point 裁掉 20pt 系统状态栏。Release 模拟器构建通过，二进制中不存在 `design-fixture`、`DESIGN_FIXTURE_ROOT` 或 `ShudengDesignFixture`。该基线曾记录视觉未通过状态；书架已由 #25 更新，其他页面仍保持失败或未验收。

## 允许适配差异

只允许以下变化，并必须在对应页面记录原因与截图：

1. 真实书名、作者、回答和时间造成的自然折行或高度变化。
2. Dynamic Type 辅助字号导致的换行、单列书库或内容增高。
3. 安全区、状态栏、键盘、权限弹窗等系统界面造成的可用空间变化。
4. 因设备宽度不同而在 375/390pt 下发生的等比例尺寸变化。

以下不属于允许适配：替换导航栏或底栏、删除品牌行、缩小页面标题、把卡片改成系统列表、减少信息、改变主次顺序、用通用系统弹层代替设计的底部面板。

## 验收流程

1. 用固定夹具和固定内容准备书架；截图 375 × 667 浅色，与原型同尺寸对照。
2. 修复书架，重复两种尺寸与浅深色；通过后再做空/准备状态。
3. 按笔记、对话、我的、阅读、问答、引用的顺序逐页闭环。
4. 每次只更新本矩阵中实际取得证据的单元格，不把“代码已实现”写成“视觉通过”。
5. 最终运行行为回归，确认视觉返工没有破坏引用往返、保存和阅读定位。
