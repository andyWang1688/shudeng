# 阅读 Agent 与 RAG 重构

更新：2026-11-04。状态：已进入实现与验收，尚未发布。已确认选型见 [ADR-0019](../adr/0019-react-native-langchain-architecture.md)。实现分支为 `codex/reading-agent-rebuild-20261104`，关联架构任务 #57；此前 #55 的单次生成限制由本次 Agentic RAG 决策取代。自动化检查与设备验收分别记录，不能互相替代。

当前证据与未验证项见[实施验收记录](2026-11-04/reading-agent-acceptance.md)。

## 已确认范围

- AI 与 RAG 一起重构，优先采用 LangChain 生态的成熟能力。可参考范围为当前整本书，不扩展到整个书架；提问选文用于明确问题指向。
- 问答内容使用 assistant-ui React Native，保留阅读内弹层与上拉全屏的窗口交互。
- 联网采用模型服务商的内置搜索，沿用模型配置。它属于服务商执行的工具；书内搜索与原文读取由书灯执行。开关在各模型服务的编辑页单独保存，默认关闭，下一次提问生效。旧全局偏好只迁给当时选中的服务，已有服务级值优先；其他服务及新增服务不继承该开关。
- 回答提供书内依据与网页来源，区分引用、补充解释和推断；书内引用可回到原文，网页来源可打开出处。
- 用户可自定义阅读 Agent 的基础行为与人设。采用用户级统一指令，底层可按 AGENTS.md 表达；它属于产品配置，不修改开发仓库的同名文件。

## 建议执行流程

导入或准备检索资料时执行：提取章节与原文位置 → 切块 → 生成本地向量 → 保存检索索引。只有书籍内容或索引方案变化时才需要相应更新，不在每次提问时重新为整书生成向量。

提问时装配当前书身份、问题、提问选文及其位置、必要的对话历史。建议为选文问题读取有界的相邻原文，减少“这句话”“他”的指代丢失；无法精确定位时明确标记，不凭相似文字假定位置。

Agent 在统一规则和按需加载的阅读 Skills 指导下，调用书内搜索、原文读取、目录读取；允许联网且服务已确认支持时，可调用服务商内置搜索。得到工具结果后可调整查询、继续读取，或在依据足够时回答。这是 Agentic RAG：RAG 的检索嵌在查书工具内，不强制在回答前再运行一轮独立的向量检索。

工具调用受次数、时间、输出容量和取消信号约束；达到限制时保留已取得的依据，说明未查清的部分。最终回答按需流式显示，引用在核对后作为可点击来源保存；关闭弹层不取消运行。

## 导入、切分与索引建议

EPUB 按 spine 阅读顺序逐章提取 XHTML 正文，保留章节、资源 href、段落顺序和原文位置；不能使用随字号变化的屏幕页号作为稳定来源。PDF 以页码和页内文字位置为基础提取文本，阅读顺序、双栏、页眉页脚及跨页句子需要针对真实文件验证。清理检索文本时保留到来源文字的映射，不能让去空白等处理破坏引用位置。扫描页没有可用文字时不建立虚假的语义资料；OCR 不在已确认范围内。

切分先尊重章节、段落和句子，再按实际 embedding tokenizer 的长度限制约束；超长句仍需有界切分。候选方案允许少量边界重叠、命中后扩展相邻原文，但具体长度与重叠量由题集和移动端资源测量决定，不照抄通用示例的固定参数。重叠片段与重复原文必须依据来源位置去重。

向量是供相似度比较的数值坐标，不是可还原原文的压缩包。索引同时保存来源身份及版本、片段 ID、原文、章节/页码、精确位置、向量和 embedding 模型版本；关键词索引指向相同的片段身份。整书无需每轮重新向量化，问答时只为当前搜索查询生成向量；文档和查询必须使用同一向量空间。更换 embedding 模型或切分/提取策略需重建或版本化索引，不能混用不兼容向量。

当前实现保留本地 ONNX、SQLite FTS5/BM25、向量余弦和 RRF。具备 tokenizer 的 embedding provider 先完成准备，再按实际输入上限约束切片；超长输入显式拒绝，查询按可容纳片段生成向量后合并。无重叠切片保持准确原文 offset，命中后通过前后文工具扩展。长中文问句使用有界术语候选召回，避免整句单字 AND 导致漏检。参数仍需通过真实书题集评估，不能以测试通过代表最佳召回效果。

## 工具契约建议

本次实现新增 `get_book_outline` 和 `read_book_passage`，并保留 `read_page`、`read_chapter` 的旧入口。工具结果是带 JSON 元数据的有界文本，以下描述其业务契约；字段以 `packages/core/src/agent/book-source.ts` 和 `tools.ts` 为准。

| 能力 | 输入 | 返回给 Agent 的内容 |
| --- | --- | --- |
| 书内搜索 `search_book` | 查询词或自然语言问题，可选章节约束和结果容量 | 有界原文片段列表、来源 ID、章节/PDF 页码、可继续读取的引用、截断或检索可用性说明 |
| 原文读取 `read_book_passage` | 选文位置或搜索返回的引用，可选前后文范围、续读游标 | 更完整的连续原文、章节/PDF 页码、来源 ID、真实覆盖范围和后续游标 |
| 目录读取 `get_book_outline` | 当前书，可选目录层级或游标 | 稳定章节 ID、标题、层级及可读取引用；大目录同样有界返回 |
| 内置联网搜索 | 遵循对应服务商的工具协议，由模型产生搜索请求 | 服务商实际返回的网页材料、来源及可用的搜索状态；不伪造应用拿不到的网页正文或执行细节 |

当前书身份由宿主绑定；工具实现不接受模型绕过当前书范围。搜索在内部结合关键词与向量召回、去重排序；Agent 首版无需分别调用关键词和向量工具。关键词用于名称、术语、原句，向量用于同义表达和自然语言问题。两路结果均只作为候选，相关性分数不等于事实置信度。

每段结果内部保留稳定来源身份、书籍内容版本、原文及精确位置；给模型展示可引用的来源 ID 和文本。向量数值不作为问答上下文返回。建议向 LangChain 的 Document/检索接口做必要适配，避免为统一名词增加无用途的层。

搜索返回较短片段，原文读取负责展开及连续读取，两者都标明容量限制。候选先继续评估现有本地 ONNX、SQLite FTS5/BM25、向量余弦与 RRF；分块、模型、排序可按真实题集替换，不因框架示例默认引入云向量库或云端 embedding。

### search_book 调用示例（使用虚构材料）

Agent 结合问题、选文和历史，将“作者为什么这么说”改成带有实际主题的查询。示例输入：

~~~json
{ "query": "群体压力如何影响独立判断", "limit": 5 }
~~~

当前书身份由应用绑定，无需模型填写。内部先在当前书与可选章节范围内召回关键词候选，再用同一个查询的 embedding 召回语义候选；关键词路径可以提取术语/短语，具体策略需评估。按位置身份合并去重与排序，在结果条数和总文字预算内返回原文。结果排名不能作为命题正确概率。

简化输出示意（仅展示一项）：

~~~json
{
  "results": [
    {
      "citationId": "E1",
      "text": "人们有时会为获得群体接纳而放弃自己的判断。",
      "chapter": "第3章 群体与个人",
      "readRef": "p_031"
    }
  ],
  "semanticAvailable": true
}
~~~

citationId 用于本轮回答引用，readRef 是书灯解析的原文读取引用，背后绑定当前书、稳定片段及索引版本；它不是轮内引用编号。模型可以据此读取更多原文或换查询再次搜索；重复调用相同查询不保证出现新材料，工具仍受预算约束。上面的 JSON 只演示业务字段，实际工具按每项元数据加原文的格式返回，并标记截断及续读游标。

## 规则与 Skills

给产品 Agent 单独维护基础规则、用户自定义指令与阅读 Skills。基础规则涵盖当前书范围、原文与补充说明区分、联网权限及真实引用要求；用户自定义指令控制人设、语气、语言、详略、提问方式与偏好的阅读协作方式；Skills 分别描述选文解释、书内查证与整书总结的工作方法。框架需显式配置规则与 Skills 来源；文件存在不等于自动加载。

设置页提供可直接编辑的“助手自定义指令”，预填默认模板并可恢复默认，允许 Markdown。首版作为统一用户配置应用于所有书籍，不要求读者自行管理目录。保存后下一次发问生效；当前运行使用启动时的配置快照，已保存回答不被追溯重写。设置保存在现有 SQLite 偏好表中，不改模型密钥；保存失败保留稿件，损坏配置明确报错。

“我的”统一通过“AI 与助手”进入模型、阅读助手与本地资料设置，取消重复的阅读助手入口。阅读助手页只维护指令，模型编辑页维护对应服务的联网开关与能力说明；外部 MCP 工具收进次级列表，保留已有配置和调用授权。

Skills 能指导何时换搜索词、读取前后文、检查反例或扩大章节覆盖；模型结合问题、工具描述和实际结果作决定，不机械固定检索次数。反复检索必须有补充依据的目的。人设和 Skills 不能通过文字开启用户关闭的联网、改变当前书工具权限、伪造出处或解除运行预算。

这些规则属于书灯产品运行时，与仓库根目录 `AGENTS.md`、`.agents/skills/` 中供开发助手使用的编程技能分开。检索材料属于资料，不能升级为工具权限或全局规则；当前书范围、联网开关与资源限制由代码执行。

通过 `deepagents/browser` 的官方 memory、skills、filesystem middleware 读取运行内 StateBackend 的产品 AGENTS.md 与三个阅读 Skills；只开放 `read_file`，不开放写入、执行或子 Agent。文件只包含助手规则，不挂载设备文件系统。浏览器入口仍会静态导入可选 LangSmith 云沙箱；Metro 对这个未使用的接口做精确失败适配，实际调用会报不可用，不引入 Node 文件系统兼容层。Hermes 导出已通过，真实设备调用与来源展示仍需分别验收。

## 回答与引用

书内工具登记本次实际提供的原文和来源，模型使用来源 ID 引用。应用核对 ID、引用文字与位置的对应关系；保留精确原文回跳能力。现有 `EvidenceRegistry` 和 `verifyCitations` 可作候选基础，仍需评估来源身份、重复原文、截断与跨轮持久化。

网页来源来自服务商实际返回的引用元数据；链接与标题保存到消息中，与书内来源分开。来源 ID 和链接不由模型自由编造。原文匹配核对能检查出处存在，不能单独证明推断正确，仍需回答质量验收。

有依据的关键书内结论应带引用；没有依据时说明，不为每句普通知识硬配出处。整书总结须规划章节覆盖、按容量逐步读取和分层归纳；仅有少量相关片段时明确回答覆盖范围，不声称已经读完整书。

## 建议首批验收

1. 选中含指代的句子提问，依据准确的前后文解释，选文位置不串到书中重复段落。
2. 术语原词与同义问法均能找到目标依据，允许跨章节补查，始终限当前书。
3. 全书总结具有章节覆盖记录；读取受限时明确未覆盖部分，不把局部命中当作全书结论。
4. 联网关闭、不支持或失败时状态真实；启用后保留实际网页出处，与书内依据区分。
5. 书内与网页引用保存后可回看；窗口展开、收起、关闭重开不清空草稿或重启问答，引用按各自类型跳转。
