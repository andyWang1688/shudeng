# v0.5.6 模拟器正式包验收

2026-11-27 在 Shudeng Small（iOS 26.5）安装从最终 ZIP 解压得到的书灯 0.5.6（构建 19）。主程序、Hermes 和 Expo 配置与交付包一致，覆盖安装前后均有 8 本书、5 条标注、36 个对话。打开《段永平投资问答录》的旧笔记，显示书灯编辑器，系统标注菜单未出现。

源码类型检查、文档站、Release 编译、arm64 架构、压缩包完整性、深度签名和 127 个 npm 包的许可审计通过。并行构建时移动端有超时和后续断言失败，构建结束后单独执行移动端测试全部通过。按各包最终结果合计 1,163 项通过、9 项默认跳过。完整跨页操作另见 [PDF 标注验收](../2026-11-26/pdf-annotations.md)。
