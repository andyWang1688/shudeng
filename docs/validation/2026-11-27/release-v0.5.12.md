# v0.5.12 模拟器验收

在 v0.5.11 源码上，用真实问答组件和 assistant-ui 运行时复现了草稿覆盖。React 分批呈现输入更新时，输入「问一下」后会退回「问」。修复后，输入框读最新草稿，多行文本在关闭并重开原会话后仍完整。69 项问答与会话定向测试、移动端类型检查和文档站构建通过。关联 [#61](https://github.com/andyWang1688/shudeng/issues/61)。

复用现有构建目录完成一次 Release 构建，分发包 Info.plist 和 Expo 配置均为 0.5.12 / 25。arm64、深度验签、ZIP 完整性和 127 项 npm 许可检查通过。Shudeng Small（iOS 26.5）覆盖安装后保留 8 本书、5 条标注和 39 段对话，已安装文件与最终 ZIP 一致。

在 v0.5.11 上实测已有 PDF 对话可从末条回答滚回首条问题。在 v0.5.12 打开同一对话，用软件键盘回车另起一行，收起再重开，界面保留两行未发送内容。已有真实 DeepSeek 联网证据见 [v0.5.11 验收](release-v0.5.11.md)。[交付清单](../../../delivery/releases/v0.5.12/release-manifest.json)

## 中文输入复查

沿用已安装的 v0.5.12（构建 25）。用 iOS 软件键盘的简体拼音选出「你好」，关闭并重开问答后仍可见。另用软件键盘输入两行中文，从系统编辑菜单剪切并粘贴回输入框，两行文字及换行在重开后保留。

快速注入同一串英文按键时，问答输入出现词语替换，对话搜索框也出现漏字，iOS「设置」搜索框的对照样本完整。快速输入偏差的归因仍待核实。复查结束后恢复英语键盘，书籍、标注和对话计数仍为 8、5、39。iPhone 14 Pro 在 `devicectl` 和 `xctrace` 中均显示离线。真机上的输入、后台恢复和 DeepSeek 联网待接线验收。
