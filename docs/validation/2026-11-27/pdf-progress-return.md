# PDF 翻页与返回问答

Shudeng Small（iOS 26.5），已发布的 v0.5.10（构建 23）。从《段永平投资问答录》的第 380 页打开书内问答，请模型根据第 41 页解释卖出时机。回答保存了 3 条书内引用。点其中第 117 页引用后，PDF 高亮了原句。点「返回问答」恢复同一轮回答。SQLite 中的续读页为 117。该轮关闭联网，回答状态为完成，网页来源为 0。

在 v0.5.10 源码的受控回归中，延迟第 40 页写入，等待期间让 PDF 翻到第 41 页，再使第 41 页写入失败。旧实现仍确认返回成功，续读页留在 40。修复后，返回操作会等待期间加入的最新写入。写入失败保留现有提示，再试成功后存到第 41 页。39 项 PDF 与问答会话定向测试和移动端类型检查通过。竞态修复尚未打包，真机当前不可用。
