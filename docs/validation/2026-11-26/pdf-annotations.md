# PDF 标注验收

## PDF 跨页选文保存完整标注

在 Shudeng Small（iOS 26.5）打开《段永平投资问答录》，连续模式下拖动 PDFKit 手柄，从文件第 380 页尾选到第 381 页首。旧版的问答草稿和笔记编辑器都拿到跨页摘录，但 SQLite 只写第一页坐标，保存后第二页没有笔记标记。

新版笔记保留完整摘录和两页矩形，SQLite 只有一条标注；点第 381 页可以打开同一笔记。关闭进程并重开后，标注列表仍保留完整摘录，点列表回到第 380 页。另存跨页高亮，两页都显示绿色；从第二页改蓝，两页一起更新，再点当前颜色将两页高亮一起取消。旧单页笔记仍能从列表回跳并打开。只移除了本轮产生的测试标注。

两项新增回归使用实际阅读器保存流程与 SQLite，修复前均缺少第二页坐标，修复后通过。类型检查、1,217 项默认测试、模拟器 Release 构建及覆盖安装通过；9 项默认跳过。问答只验证了跨页草稿，没有发送。本轮未操作真机、未发布。[#59](https://github.com/andyWang1688/shudeng/issues/59)

## PDF 标注编辑器不再叠出系统标注菜单

同一模拟器中，点《段永平投资问答录》文件第 41 页旧笔记的文字区域，旧版会在书灯编辑器上叠出 PDFKit 的「Highlight / Remove / Add Note」。PDF 只读标记未能遮断该交互。最终版只在命中书灯自己的标注时优先处理轻点，原生长按与拖选继续由 PDFKit 处理。

最终 Release 构建并覆盖安装后，连续三次点击同一旧笔记均直接打开书灯编辑器，系统标注菜单未出现。另验证连续滚动、普通长按、拖动手柄跨页、保存跨页高亮，以及从第二页打开书灯调色板和取消两页高亮。测试高亮已删除，旧笔记仍在。本轮未在真机运行、未发布。[#59](https://github.com/andyWang1688/shudeng/issues/59)
