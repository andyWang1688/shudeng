# 对话左滑操作复查

2026-11-10，codex/ui-product-integration 未提交工作区；关联 [#59](https://github.com/andyWang1688/shudeng/issues/59)。设备为 Small、iOS 26.5，运行 dev.shudeng.visualdemo（书灯·UI），通过 demo:ios conversations 复用现有 Release 原生包，仅更新 JavaScript。正式产品对话行同步修改了源码，尚未重新部署。

## 改动与回归

Demo 和产品此前已经使用 Gesture Handler 的 ReanimatedSwipeable；本轮移除额外的长按动作菜单，轻点正常打开对话，已滑开的行先收起操作。保留读屏自定义操作、重命名输入及删除确认。操作改为分开的圆角按钮，暖灰重命名、红色删除，文字与图标使用一致层级；产品源码同时适配深浅外观的前景色。样式仍待用户视觉确认。

产品现有 screen/row 测试增加了真实处理器回归，先观察旧代码在“重复长按菜单”及“点击已展开行”场景失败，再修复通过。最终移动端类型检查与 33 项对话测试通过；覆盖轻点、收起优先和离页旧回调不能再次导航或打开对话框。

## Small 实际操作

| 操作 | 观察结果 |
| --- | --- |
| 对第一条对话轻点 50ms、返回；按住 700ms 后释放 | 均打开问答弹层，没有再弹出重命名/删除选择菜单。 |
| 拖动左滑，再点正文 | 两个独立按钮展开；点正文仅收起操作，未直接导航。 |
| 左滑后点重命名，输入“雨雪与开篇”并保存，再打开对话 | 列表标题更新，打开后原问题仍为“为什么从雨和雪开始讲故事？”。随后通过可访问自定义操作恢复原示例标题。 |
| 左滑后点删除，再取消 | 仅显示删除确认，取消后原对话仍在；本轮未确认删除。 |
| 先收起操作，切到我的再回对话并左滑 | 修复前首次进入正常、切回失效；对照重开可重复。改为按 active 启停手势后，该路径左滑成功。再保持操作展开切到我的并返回，按钮已收起、书组仍展开。 |

当前样式见[设备截图](conversation-swipe-actions.png)。切换回归的进一步第二行坐标拖动被 Device Hub 窗口缩成后台倾斜预览中断，工具报 windowNotFoundAtPosition；未将该次动作计为通过。最后返回对话列表。手势结果依据 CUA 直接操作 Device Hub；另一设备工具曾返回触控成功但无界面变化，不作为通过证据。

## 验证边界

示例数据只保留在进程内；真实数据库改名/删除、正式产品设备回归、Android、深色外观设备效果、大字体及完整 VoiceOver 未验证。浅色 Small 的当前交互已经实测，不据此宣称全部手势、跨端或性能通过。未提交、推送或发布。Demo 打包临时目录已自动回收；保留本文与两张相关交付截图。

## 第二轮：替换为系统列表组合

随后用户提供[实际操作截图](conversation-swipe-overlap-before.png)：对话文字与动作按钮重叠，整行呈半透明状态。该截图证明上一版存在未覆盖的操作态缺陷；上面的稳定态与部分动作通过不能当作整条手势通过。用户再次要求把列表滚动、分组展开和左滑整体交给成熟组件。

已核对工作区安装的 Expo UI 源码及现有 Release 包的链接对象，List、DisclosureGroup 和 SwipeActions 均已包含，不新增依赖或原生模块。iOS 独立 Demo 改由 DemoConversationList.ios.tsx 组合这三项系统能力；原 RN 实现仅作为其他平台与历史样本预览。当前没有将这一版接到正式对话数据路径。

| 实际操作 | 观察结果与边界 |
| --- | --- |
| 打开系统列表，收起首书，展开第二书，再展开首书 | 系统书组对应显示/隐藏对话，保持一次展开一本。首屏书名层级与长标题两行布局可见。 |
| 原地展开全部 12 条，通过列表 Scroll Down 操作滚到尾部，再点收起 | 尾部对话可达，收起恢复预览，未跳新页；这是实际可访问滚动，不证明指针拖动或惯性手感。 |
| 调用系统行的可访问重命名操作，改为“雨雪与开篇”，保存并打开 | 标题更新，问答内原问题仍为“为什么从雨和雪开始讲故事？”。重装后样本复位。 |
| 搜索“线索”，清空搜索 | 找到预览外的最后一条对话；搜索时书名为静态标题，没有可隐藏匹配的展开按钮；清空恢复原书组。 |
| 调用系统行的删除操作并取消 | 删除确认出现，取消后原记录保留；未确认删除。 |

移动端类型检查、Demo 打包、安装通过，继续复用 Release 原生包，只打 JavaScript。首次沙箱安装被 CoreSimulator 权限阻止，随后通过已授权的模拟器安装运行成功；失败 stage 已自动清理。

当前首屏见[系统列表截图](conversation-native-list.jpg)。设备窗口只返回后台倾斜缩略图，无法据此执行精确指针拖动；Xcode UI 工具点按返回成功但 UI 未变，本轮仍不计通过。用户回复暂时不方便将 Small 窗口置前，真实左滑、拖动中形态、松手收起、滑开后点正文及切页回来的手势本轮未验收。当前不能宣称重叠问题已通过拖动复测；Android、大字体、完整 VoiceOver、真实存储及大数据回收性能亦未验证。两轮成功打包与一次权限失败的临时 stage 均已回收；重复临时截图已删除，保留用户原图及本目录的最少对照证据。

## 第三轮：收紧子项缩进

用户认可系统组件版的观感，同时指出对话左侧留白过大。此前子项 leading=72 又叠加系统 DisclosureGroup 的层级缩进；当前将普通子项调整为 44，搜索时的平铺子项为 64，使文字与书名文字对齐，未改变系统手势或展开实现。

类型检查、格式检查、JS 打包与安装通过。Small 现版普通列表见[截图](conversation-native-list-spacing.jpg)：标题左端与书名文字对齐，第二条标题可完整显示在一行。实际输入“森林”后另核对搜索结果，两个结果的标题也与书名对齐；收起键盘并清空后恢复原列表。保留一张当前截图，已删除检查用搜索截图。原生构建未重跑，临时打包目录已自动回收；本轮没有新增指针左滑验收，不改变第二轮的未验证边界。

## 第四轮：接入真实产品并实测左滑

系统组合已接入 dev.shudeng.integration 的 iOS 对话路径，默认平台实现继续保留。Small 的真实 13 条对话书组完成原地展开、轻点打开、实际指针左滑、重命名并恢复、删除取消及预览外尾部搜索。左滑与点击通过本机 serve-sim 镜像操作，绕过 Device Hub 后台缩略图；原有截图与未通过的历史结果保留。当前[左滑截图](integration-conversation-swipe.jpg)和完整操作、测试及未验证边界见[真实接线验收](settings-integration.md)。本轮未确认删除原有对话，也未发布。
