# 阅读与书架组件复用

2026-11-24，本地 Release 构建，Shudeng Small，iOS 26.5。排版关联 [#62](https://github.com/andyWang1688/shudeng/issues/62)，产品接线关联 [#59](https://github.com/andyWang1688/shudeng/issues/59)。

| 场景 | 操作与结果 |
| --- | --- |
| 中文 EPUB 排版 | 《红楼梦》第三回滚动模式正常显示，旧高亮和笔记波浪线可见。点原有高亮记录，回到标注原文。受控测试覆盖出版样式、无样式、固定版式、英文及书内语言，确认只有无出版样式的中日韩可重排章节注入 Readium 默认样式。 |
| 系统分段选择 | 《红楼梦》导航弹层读取到目录、书签和标注系统分段。切换书签后显示已有书签，切换标注后显示旧高亮和笔记。阅读设置全屏时将主题从明亮切到深色，系统选中状态正确，再切回明亮。 |
| 书架动作面板 | 长按《红楼梦》封面打开 iOS 动作面板。点「移除原书」打开第二次确认，取消后书仍在。点「更多操作」再选「查看标注」，显示《红楼梦》的原有标注。首种 Expo ContextMenu 接法在 Small 上会把长按传给开书按钮，最终使用 ActionSheetIOS。 |

全量自动化 1,161 项通过，9 项跳过。四个包类型检查、内联 EPUB 资源生成、Release 构建及 Small 覆盖安装通过。删除、失败重试及过期原生回调由受控测试覆盖。书架确认卡保留原有关闭回调，移除和删除仍需独立确认。阅读方式保留单独禁用仿真翻页的能力。

已复用的底层包括 Foliate 分页和连续滚动、PDFKit、assistant-ui、Gorhom Bottom Sheet 及系统列表。待验证的候选包括对话改名和系统选文菜单，需要分别覆盖离开页面后的回调、从选区进入高亮或问答的时序。真机、iPad、完整 VoiceOver、PDF 实际点击、与 Apple Books 的同书同页对照及正式分发许可生成尚未验证。本轮未发布。
