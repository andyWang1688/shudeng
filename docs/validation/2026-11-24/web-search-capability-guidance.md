# 联网开关与模型能力提示

2026-11-24，用户在手机 iPhone 14 Pro 上开启联网搜索后询问“你能联网搜索不”。模型回答本次没有联网搜索工具。

## 现场证据

从手机应用数据库读取该轮已保存状态：

- `webSearchStatus.status` 为 `enabled`，消息为“已允许服务商内置搜索；是否实际搜索取决于本次问题。”
- 该轮只有一次模型步骤，没有调用任何书内或联网工具。
- 因此开关和 DeepSeek Flash 能力解析已经成功，故障在模型未收到明确的运行时联网状态，随后自行回答成工具不存在。

## 修复

在原回归上先失败：启用 DeepSeek Flash 服务端搜索时，模型系统提示缺少“本轮已启用联网”的明确状态。

修复后，每次模型请求会把当前联网状态追加到系统提示：

- 已启用：明确告知可以联网，不能回答没有工具；具体网页问题仍由模型决定是否实际搜索。
- 不支持：附上具体原因，例如 DeepSeek Chat 显示“需使用 deepseek-flash”。
- 搜索失败：禁止声称已经查到网页。

问答界面在联网已启用但本轮没有实际搜索时，也会显示联网状态，不再完全隐藏。

## 验证范围

新增受控回归覆盖 DeepSeek Flash 已启用和 DeepSeek Chat 不支持两种系统提示。全量测试 1,161 项通过、9 项跳过、0 失败；四包类型检查通过。

最终 Release 已重新构建、安装至 iPhone 14 Pro 并启动。真实 DeepSeek Flash 重新提问后的工具使用和网页引用仍待手机复测。
