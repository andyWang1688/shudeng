- 开发包：`dev.shudeng.integration`，显示名「书灯·开发」。复用已有 Release 模拟器原生包，仅更新 JS 与资产，再签名安装；正式版和视觉 Demo 保留。
- 数据：独立沙盒通过正式导入、标注与对话存储 API 建立 EPUB/PDF 夹具、5 条标注与 14 段历史样例；历史回答明确注明是验收样例。没有复制用户正式书库。初始化临时入口已删除，最终安装包使用正常 `expo-router/entry`。

## 本轮实现

书架、笔记、对话和设置采用已确认的文字层级、配色与固定页头/搜索。分组列表保留虚拟化，默认预览、原地展开，搜索和导出覆盖完整数据。笔记点击行内展开，再明确回原文；对话只保留标题，重命名和删除继续使用原持久化与对象身份保护。

EPUB/PDF 保留真实引擎，工具栏覆盖固定正文视口。目录、搜索、设置、笔记和问答组合 Gorhom 共用弹层，可展开全屏；设置直接作用于原书。问答保留 assistant-ui、真实执行链、草稿、流式、取消、历史与引用。正式页面不导入视觉 Demo 或其 fixtures。

独立复审发现并修复：关闭笔记动画期间仍可触发保存的竞态；EPUB 卸载/换书后的旧异步结果覆盖当前书状态。保存本身仍能完成，UI 发布按 owner 失效。旧笔记手写拖拽几何与其专用测试随容器替换移除。
