## 实际操作与结果

| 场景 | 操作与观察 |
| --- | --- |
| 书名与内容层级 | 书名 23pt 粗体，内容 17pt 并缩进；Small 上每书预览 2 条，同书共 12 条对话时仍有“查看全部”入口。切换到另一本后，前一本收起。 |
| 完整历史与返回 | 打开“查看全部 12 条对话”，进入固定书名与数量的独立列表；搜索“线索”找到第 12 条，返回后总览搜索保持原值。未测千条数据或真实分页性能。 |
| 预览以外的笔记 | 总览搜索“迁徙”，找到第 4 条笔记；清除后恢复原书组预览。条目预览数量没有限制搜索范围。 |
| 连续展开收起 | 连续点击同一书组三次后，暴露状态与最终收起一致；再次打开后恢复条目。仅验证终态，不据此声称动画帧率、物理手感通过。 |
| 长提问选文 | 打开《瓦尔登湖》对话与全屏：问题完整展示，选文默认两行，点击后展开，再点击收回。历史列表不直接展开整段选文。 |

复核中发现 Demo 的预加载弹层使用 display:none，首次打开当前默认书对话时没有完成内部尺寸计算。已移除对弹层容器的 display:none，使用组件关闭索引、pointerEvents 和可访问性隐藏控制；修正后首次打开《瓦尔登湖》对话成功，收起后列表可继续操作。

## 后续动效调整

用户认为上一版动画像幻灯片。已去掉标题的下拉缩放/位移、文字淡入淡出及多层布局弹簧；展开内容持续挂载，只让裁剪容器高度与箭头在 220ms 内连续改变，快速输入中断当前过渡并转向最新状态。收起的内容禁触控并从可访问性树隐藏。首次展示直接按展开状态布局，不播放入场。

本轮 Small 复核：切换书组后旧组内容从可访问性树消失；连续三次点击后状态与最终收起一致；笔记展开后“回到原文”可访问；返回对话没有隐藏条目挡住书名。类型检查通过；这些检查证明状态与入口正常，不代表动画帧率、连续触屏手感或减少动态效果实际验收。未新增截图或原生构建，Small 停留在对话页，供用户直接评审。
