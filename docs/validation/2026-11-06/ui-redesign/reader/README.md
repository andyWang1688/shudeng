# 阅读入口检查

## 当前版：PDF 悬浮工具栏

移除 PDF 上方 58pt 与下方工具栏高度的固定留白，PDF 阅读容器铺满；上下工具栏改为带圆角的局部悬浮表面。显隐仅影响控件，不改变 PDF 尺寸、页码和正文位置。此节取代下方“固定避让工具栏”的旧版布局。

在 Small 打开“PDF 文字样本”，截图确认页底正文延伸到悬浮工具栏背后；点击专注，工具栏消失，页面宽度、缩放与文字位置保持一致，上下不再留工具栏占位。保留系统状态栏；PDF 自身页面留白不作裁切。

证据：[悬浮工具栏](pdf-floating.jpg) · [PDF 专注](pdf-immersive.jpg)。类型检查和 JS 安装通过，未新增原生构建。PDF 触控缩放、选文标注、单击正文恢复、长文档及真实书籍仍未验证；当前截图是本地两页夹具。

## 统一弹层、同色取消与 PDF 补充

设置、目录、AI 问答与标注编辑共用 DemoSheet（Gorhom），统一两档吸附、根容器全屏、圆角和安全区。设置初始高度由 32% 提高为 46%，字号完整可见；所有面板有 100% 高度及显式全屏入口。阅读器正文安全区与弹层宿主分离，工具栏显隐不重建内容。此轮未连接正式业务。

实际操作：以 detail=highlight 打开样例，点击已选黄色，弹层关闭；直接截图确认黄色消失、笔记波浪线保持。打开阅读设置、点击全屏，截图确认覆盖整屏、顶部安全区正确、字号控件完整；目录同样可展开全屏。设备工具对拖动条的 Increment 返回未变化，故不把这次辅助动作视为上拉手势通过；物理拖动手感尚待用户核对。

书架“PDF 文字样本”成功加载既有原生组件和两页本地夹具。设置只有单页/连续滚动；选择单页后，目录“页面”中跳第 2 页，截图实际出现第二页文字。后续固定避让工具栏防止页首遮挡，最终类型检查和 JS 打包安装通过。PDF 选文标注、缩放、扫描页、大文件、进程重启保存和真机性能未验证。原有笔记等仍只存 Demo 内存，临时 app 由运行脚本回收。

证据：[同色取消](highlight-removed.jpg) · [紧凑设置](settings-compact.jpg) · [设置全屏](settings-full.jpg) · [目录全屏](contents-full.jpg) · [PDF 第 2 页](pdf-page-two.jpg) · [最终 PDF 留白](pdf-final.jpg)。最后一张在修正后重新安装拍摄，确认页首标题完整。最终回归 AI 问答的展开与关闭：全屏、输入框和当前书名正常；未调用真实模型。结束停留 PDF 阅读页。后续历史记录继续保留，不混称当前验收。

独立“书灯·UI”Demo，codex/ui-design-demo 分支；Shudeng Small、iOS 26.5、竖屏、浅色。不加载产品路由、书库、数据库或模型。实现与正式接线边界见 [Demo README](../../../../../apps/mobile/src/ui/visual-demo/README.md#阅读入口与状态提案)。

## 后续收敛：实时设置与标注

用户要求收敛重复入口后：书签只在右上角添加，目录列表不再增加；字号只放书内，设置即时作用于正文，移除复制的示例文字与取消回滚语义；移除上栏章节提示、下栏段落计数和可见“退出专注”。正文改用已安装的 react-native-webview，以系统文字选区和菜单提供高亮、笔记的示例入口，未增加原生依赖。

实际检查：打开阅读设置，从 20 连续调到 24，直接截图确认背后原文变大、重新换行，高亮与笔记波浪线仍可见。用 detail=note 直接打开样例编辑器，修改后保存；返回笔记页搜索新增正文，得到唯一匹配记录，回到原文再次预览编辑器时值保持一致。清空正文后保存不可用，再关闭编辑器。最终以无 detail 参数重新安装，恢复正常阅读启动页。

证据：[精简阅读页](simplified-reading.jpg) · [即时字号](live-font.jpg) · [笔记编辑](note-editor.jpg)。截图均为独立样本；不是正式用户书籍或真实数据库结果。类型检查、内嵌 JavaScript 语法检查与 git diff --check 通过，安装复用现有原生包。

未验证：从真实长按手势进入系统选文菜单、新建标注、点按已有标记、四色切换、正文短触恢复工具栏、跨段选区、读屏及键盘输入布局。Device Hub 可操作 RN 控件，但未向工具暴露 WebView 内的文字目标；一次截图坐标点击返回 windowNotFoundAtPosition，不计为通过。高亮与笔记编辑已接入示例逻辑，不能因此宣称选区触控验收完成。
