## 实际检查

| 输入与操作 | 观察到的结果 |
| --- | --- |
| 在四个底部目的地之间切换 | 页面可打开，页头与搜索位置一致；书封、列表和设置分组可见。 |
| 书架搜索 zz-no-match，再清除搜索 | 显示 0 本与空结果状态；清除后恢复 4 本示例书。 |
| 展开第一条笔记，点击回到原文 | 显示展开状态和入口，进入对应书名及章节的示例阅读页。仅验证示例页面跳转，未验证真实原文锚点。 |
| 从阅读页及对话列表打开问答，点击全屏、展开引用、输入、收起再打开、发送 | 弹层和全屏可见，引用展开；键盘出现时输入框位于键盘上方；“测试草稿”收起重开仍保留；发送后出现新增示例消息，输入清空。回答为本地固定内容。 |
| 我的 → AI 与助手 → OpenAI；阅读外观选择 23 号字 | 联网搜索位于模型服务详情，返回层级正确；字号选中状态更新。设置仅在 Demo 内存中，不改变真实服务或阅读设置。 |

设备工具的坐标触控曾报告成功但页面未变化，该结果不算通过。后续操作使用 Device Hub 的原生可访问控件完成，并用模拟器直接截图核对布局。检查发现弹层默认将内部内容合并为可访问元素，已在 Demo 中关闭容器分组，让输入、关闭、全屏和引用能够独立操作；这不代表完整读屏验收。
