# EPUB 目录跳转后返回原处

环境：本地工作区（v0.5.5 之后的未发布改动）；Shudeng Small，iOS 26.5。独立示例和产品使用同一个返回按钮。

| 输入与操作 | 预期与实测 |
| --- | --- |
| 独立阅读示例：目录点「春天」，再点「返回原处」 | 模拟器辅助功能树在跳转后出现返回按钮，返回后消失。 |
| 产品：《人生财富靠康波》「康波中的价格波动」中段 → 推荐序一 → 专家导读 → 返回原处 | 两次换章后均有返回入口。成功返回后入口消失。只读查询本机阅读进度，起点和终点的完整 CFI 一致：`epubcfi(/6/14!/4/14,/16/2/1:249,/20/2/1:96)`。 |
| 同一起点 → 推荐序二 → 字号加一档 → 返回原处 | 回到原章。新页从原段字符 243 开始，包含原先的字符 249；字号改变后的页边界不同，不能用页码比较。已在模拟器恢复原字号。 |
| 受控桥接回执 | 重复点击只发一次定位，失败可重试。同页跳转不新增返回按钮，切书后迟到的回执不修改新书。 |

移动端类型检查、Release 模拟器构建通过；运行阅读状态、目录、共用工具栏与 EPUB 高亮的 4 个测试文件，41 项通过。未验证：真机、VoiceOver 实际朗读、切换阅读方式后的返回及所有书籍的特殊版式。未发布。

**11 月 26 日补测：从滚动切到分页后返回。** 在同一模拟器的当前 Release 安装包中，打开《人生财富靠康波》第 01 章中段，记下可见原文和位置：段落 `/6/14!/4/14/16/2/1`，起点为字符 235。通过目录跳至第 02 章，在阅读设置切成「分页」，原文下方「返回原处」仍可用。点击后按钮收起，显示第 01 章同一段，当前页覆盖字符 74 至 306，包含原起点。测试结束后切回滚动，用阅读器定位回起点并退出；只读核对，保存的完整 CFI 与测试前逐字一致。

**连续滚动停下后的保存。** 用可控时钟让目录跳转和返回相隔 100 毫秒。旧代码只写入跳转后的章节，界面回到原处后即使停下来，数据库也不会更新，直到退出、切到后台或再次滚动。修复后的回归确认上次写入满 1.2 秒时会补存返回位置，无需额外手势。

Shudeng Small 上打开测试 EPUB 的滚动模式，滑动后停下，应用仍在阅读页时 SQLite 已保存段落字符 543–792。打开目录点第二章，页面显示两章交界处。点「返回原处」后按钮收起，SQLite 的 CFI 与跳转前逐字一致。直接终止并重启应用，重开后仍从同一段开始。全量 1,192 项测试通过、9 项默认跳过，类型检查、Release 构建与模拟器覆盖安装通过。两次跳转严格相隔 100 毫秒的情况由自动化回归覆盖，真机待验证。
