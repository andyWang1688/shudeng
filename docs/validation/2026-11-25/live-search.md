# DeepSeek 联网实测与长回答滚动

在 Shudeng Small（iOS 26.5）使用模拟器自有配置、官方端点和测试书，询问「Chat Completions 的联网搜索工具叫什么，给出官方网页来源」。关联 [#55](https://github.com/andyWang1688/shudeng/issues/55)。

| 场景 | 结果 |
| --- | --- |
| 改前真实请求 | 回答给出 `deepseek_web_search`，SQLite 记录搜索完成，但保存的网页来源数为 0。 |
| 改后重问同一问题 | 回答完成，保存了 [Web Tools – DeepSeek API Docs](https://api-docs.deepseek.com/guides/web_tools)。受控回归另验证：纯搜索命中不充当回答引用，模型自写且未命中的地址不会展示。 |
| 重启书灯后查看长回答 | 修复前全屏时来源位于屏幕下方，XCTest 滚动后仍不可点。按输入框上沿约束消息列表高度后，同一条已保存的来源可点，Safari 进入前台。 |
| AI 服务编辑 | 保存既有服务保持原列表顺序。已保存且未编辑的配置在连接测试完成后不再提示尚未保存。 |
| iOS 联网开关 | Apple 界面测试中，旧开关从开启切至关闭后仍读到开启；更换后，连续关闭、开启、关闭并保存，重开仍为关闭。模拟器已恢复测试前的 `deepseek-chat`。 |

半屏、全屏分别通过滚动至已保存链接并打开 Safari 的界面检查。全工作区类型检查、iOS Release 模拟器构建通过；自动化 1,167 项通过、9 项跳过。真实 iPhone 未连接，未发布。两次抽查不代表所有问题都会触发搜索，也不能保证每次回答都会附引用。

同日用当前源码连续两次构建 Release 真机包（通用 iPhone 目标，不安装）。两次 JS bundle 的 SHA-256 均为 `b1d114f0dd88136337e06a0fb6cc9733c847ac7e3a100e78c4853d0f40546594`，平台为 iPhoneOS；深度签名检查通过，开发描述文件覆盖目标 iPhone 14 Pro，有效至北京时间 2026-12-01 17:56。注入构建失败后，临时文件被回收，上次成功包的签名仍有效。手机离线，覆盖安装、系统启动和手机内问答留待接线实测。
