# EPUB 字距和行距

2026-11-23，本地 Release 构建，Shudeng Small（375 × 667 pt，iOS 26.5）。[需求 #62](https://github.com/andyWang1688/shudeng/issues/62)

| 场景 | 操作与结果 |
| --- | --- |
| 独立示例 | 《瓦尔登湖》样本两项间距由标准改为宽松，关闭设置，原段落字距变宽后重新换行，行距也增大。 |
| 既有书设置 | 覆盖安装后《红楼梦》仍是滚动模式和 150% 字号，两个新设置显示标准。最终构建在初始弹层可完整看到两组控件。 |
| 当场应用与重开 | 在滚动模式分别选字距宽松、行距紧凑，正文重排。退回书架后重开，仍显示两项选中档位，SQLite 行也保存对应值。 |
| 仿真翻页 | 改成仿真后在同一章将行距由宽松改为紧凑，行间空白减少，高亮仍显示。横滑进入下一页。最后恢复模拟器上该书原先的滚动模式和两项标准间距。 |

自动化验证包含旧偏好默认值、单书持久化、两项独立保存、两种阅读桥接、原文位置回跳以及恢复标准样式。类型检查和 Release 构建通过。全量自动化 1,157 项通过，9 项跳过。

真机、完整读屏、跨端操作及特殊出版样式仍待验证。本轮未发布。

## 按数值微调

用户反馈取代三档控件。独立示例在 Small 上点击两次字距「+」、一次行距「−」，分别从 0% 调到 1%、从 175% 调到 170%。正式阅读器覆盖安装后，《红楼梦》的旧偏好字距「标准」、行距「紧凑」显示为 0%、150%。分别加两次后保存 1% 和 160%，退出到书架重开后仍显示两个新数值，并回到同一章。用户可操作的四个按钮在辅助功能树中有独立标签。测试结束后还原到 0%、150%。

全量测试 1,157 项通过，9 项跳过。类型检查、Release 构建与覆盖安装通过。未验证真机或完整读屏操作，未发布。

## 简化间距控件并放宽行距范围

字距和行距各显示名称与一对加减按钮。回归用原先的行距下限 140% 验证减号仍可用，点击后保存 135%。在 Small 的 Release 包里打开《红楼梦》，滚动模式实测从 140% 连按八次，缩到单倍行高，正文行间距离明显缩短。到达下限时减号变灰。连按八次加号后，恢复测试前的设置，SQLite 查询确认已保存。

独立示例和正式阅读器均在 Small 上检查过布局。类型检查和 Release 构建通过。全量测试通过 1,157 项，9 项跳过。真机尚未验证，本轮未发布。

## 统一字号与间距按钮

独立示例和正式阅读器在 Small 上均显示三行对齐的排版控件：字号、字距、行距各只有「−」「+」。在正式阅读器打开《红楼梦》，点字号加号，正文放大并换行，保存值由 1.0 变为 1.25；点减号还原到 1.0。移动端类型检查、24 项相关测试和 Release 构建通过，尚未发布。
