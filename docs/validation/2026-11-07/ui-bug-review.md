## 源码与环境

本轮接续 [11 月 6 日产品接线](../2026-11-06/ui-product-integration.md)，对应 `codex/ui-product-integration` 分支在 Demo 提交 `d663a77` 之后的未提交工作区；没有合并或发布。设备仍为 Shudeng Small、iOS 26.5，独立开发包 `dev.shudeng.integration`（书灯·开发）。最终安装复用既有原生包，仅重新生成 JS 和资产；不涉及原生依赖变化。

## 代码整理

删除 5 个无运行消费者的原生 UI JS 包装：NativeEpubChrome、NativeEpubNavigation、NativePdfChrome、NativePdfPanel、NativePdfSheetConfiguration。相应原生模块仍有注册或兼容职责，继续保留。

EPUB/PDF 导航复用标签栏、搜索输入、列表行及空态展示，搜索和原文定位生命周期仍由各格式管理。移除导航中无消费者的状态、全量 snapshot 序列化，以及已不使用的工具栏字段和目录内添加书签入口。右上角真实书签操作保留。关闭门禁只维护一份实现，不额外引入无消费者的 Context。
