# 隐私与数据

## 本机保存什么

书、阅读进度、书签、高亮、笔记、对话和引用快照都保存在本机。AI 服务的 API Key 保存在 Keychain。

## 什么时候联网

- **下载离线语义资料**时会联网（约 81MB）。下载的只是公开的语义资料，不包含你的书、笔记或问答。
- **检查连接或提问时**会连接你配置的 AI 服务。提问材料包括问题、选文、助手指令、必要对话或摘要，以及 Agent 按需读取的书内原文片段。
- **开启服务内置联网搜索后**，服务商可能进一步处理相关搜索查询；搜索的数据使用规则和费用以该服务商为准。

选中文字只是标记问题的指向，不代表只发送选中的那段；可能发送当前书其他章节（包括未读章节）的片段，并多次补充。书灯不把整本书文件一次上传，也不把其他书或你的笔记列表作为默认查书材料。

## 发给谁

发给「AI 服务」里配置的地址。那是第三方服务，它如何保存和使用数据，由服务商决定。

## 费用

调用费用由 AI 服务商收取。书灯不代付，也不替你做额度控制。

## 保留与删除

- 移除一本书时，默认保留笔记、对话和引用文字。引用文字之后仍可回看，但跳回原文不可用；重新导入相同文件后可以恢复定位。
- 彻底删除一本书及记录会先确认，删除后无法恢复。
- 数据只存在本机。卸载应用或更换设备会丢失，可在每本书的「标注」中导出高亮和笔记；这不是完整书库或对话备份。

## 旧版本与开发包

v0.5.0 的 `dev.shudeng.mobile` 与旧 Swift 版 `dev.shudeng.app`、开发包 `dev.shudeng.integration` 各自保存数据。本版不会覆盖它们，也没有跨包自动迁移；保留旧 App，避免卸载后丢失其中的记录。
