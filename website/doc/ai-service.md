# AI 服务

书灯不提供 AI 服务。你需要准备一个可用的 API 服务，把地址、密钥和模型填进书灯。

## 添加服务

1. 打开「我的」→「AI 服务」，添加一套服务。
2. 在「使用预设」中选择 DeepSeek、OpenAI、Anthropic 或自定义。
3. 填写这些内容：

   - 接口格式：自定义新服务选择 OpenAI Chat Completions 或 Anthropic Messages；创建保存后固定。需要另一种格式时新增服务。
   - 名称：方便你自己区分。
   - API 根地址或完整端点：用 HTTPS 地址；本机测试可以用 HTTP。不要把密钥写进地址。
   - API Key。
   - 模型：预置服务会带默认模型，也可以填自定义模型 ID。

4. 可点「检查连接」核对地址、密钥和模型；检查不等于保存，也不保证所有查书或联网能力均受支持。
5. 保存时确认发送范围与费用，再在列表轻点选择该服务。

## 管理

- 可以保存多套服务随时切换，切换不会影响已经保存的对话。
- 轻点选择服务，点右侧编辑按钮修改；已有密钥不回显，可单独更换。
- 左滑服务可删除，也可在编辑页删除。删除当前服务后需重新选择，不自动换成另一家；历史对话保留。
- 名称、地址、模型、密钥和上下文窗口可编辑；修改从下一轮提问生效，不改变正在生成的回答。

## 上下文窗口与联网

「上下文窗口」默认自动读取随应用提供的 LangChain 模型资料；识别不到时使用保守值。资料可能过期，也不能证明自定义地址的同名模型具有相同能力。

关闭自动后，可按服务商公布的值填写精确 Token 数，或 `200K`、`1M`、`1.05M` 等简写，不限制为固定档位。填写更大数字不会扩大服务商的真实限制；上下文圆环是估算，不是账单。

支持的服务在编辑页提供「联网搜索」，默认关闭。开启后，Agent 可按问题使用服务商的内置搜索；不需要单独配置搜索 API 或 MCP。兼容接口不一定支持，具体可用性及额外费用由服务商决定。

「我的」→「助手指令」可调整回答语气与偏好，保存后从下一轮提问生效，也可恢复默认。

## 费用与能力

调用费用由服务商收取，书灯不代付。同为兼容接口的服务，实际能力也可能不同，能接受多少原文、输出是否稳定，以你配置的服务为准。

## 离线语义资料

语义检索在设备上查找意思接近的原文，所需资料不随安装包分发：

1. 打开「我的」→「离线语义资料」。
2. 点按下载（约 81MB），需要联网；下载中可以取消，失败可以重试。
3. 下载优先使用国内加速线路，失败会自动切换；完成后语义资料会在后台为已导入的书准备。语义查找在本机完成，回答仍由你配置的 AI 服务生成。

资料下载完成与每本书的索引就绪是两件事；页面会显示真实准备状态。没有下载时，阅读、原文搜索、标注和书签不受影响，书内文字索引可用时仍可使用关键词查书。删除后可重新下载。

更完整的原理见[阅读问答是怎么工作的](how-reading-ai-works.md)。

API Key 只保存在本机的 Keychain 里。
