# 阅读问答

先看[阅读问答是怎么工作的](how-reading-ai-works.md)，用普通读者能看懂的方式说明书灯怎样找原文、发送什么、引用怎么核对。

## 开始前

在「我的」→「AI 服务」添加并选择服务。需要按意思查书时，在「我的」→「离线语义资料」下载约 81MB 的资料，并等待本书索引准备完成；资料未就绪时，书内文字索引可用仍可按关键词查书。

## 怎么问

两个入口：

- 选中一段原文，点「问 AI」。选中的文字用来标记问题指向。
- 阅读工具栏点「问问这本书」，不选文字，直接问当前书。

从新的选中文字发起提问会新建一段对话；追问留在同一段对话里。

## 窗口与生成

问答以弹层打开，上拉进入全屏专注，下拉收回。切换窗口大小、收起再重开不会重新发问；关闭窗口不等于停止回答，需要停止时使用停止按钮。系统中断或进程退出后，不保证原任务继续完成。

保存或更换服务时会确认发送范围与费用，普通问答不逐次弹长说明；输入区的上下文圆环可查看本轮用量估计。

## 回答与引用

Agent 可在当前整本书内多次查找和补读，范围包括未读章节。回答中的书内引用可回到原文；启用且服务支持联网时，网页来源单独显示。引用只能帮助核对，不能保证解释正确。

长对话会按所选服务的上下文预算压缩旧材料；摘要可能遗漏细节，重要问题应重新提供具体原文。仍超出容量时会提示失败，见[上下文说明](how-reading-ai-works.md#一次到底发送多少)。

## 对话历史

「对话」栏目按书分组，点「查看全部」在当前书组内展开，点标题打开对话。回看历史不重新调用 AI；继续追问才会发送。

左滑条目可重命名或删除，删除前需确认，并会移除该对话的全部轮次。移除原书后仍能回看已保存内容，但查书和引用回跳需要对应原文件。

## 需要知道的限制

回答只基于当前书里检索到的片段。检索可能漏掉理解问题所需的背景；模型也可能把自身知识说成书里的内容。重要结论请回到原文核对。
