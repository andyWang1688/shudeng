# 阅读

## 打开与继续

书架点封面打开一本书；书架顶部的「接着读」回到最近读到的位置。

## 翻页与工具栏

- 左右滑动翻页。
- 轻点屏幕中间，收起或显示工具栏。

工具栏里可以切换翻页方式：「分页」「滚动」「仿真」。

PDF 支持双指缩放。200 页及以上的 PDF 默认按页翻，减少大文档占用的内存；可以在工具栏底部切换「单页 / 连续」。

## 目录、书签与书内搜索

打开工具栏里的「目录与书签」：

- 目录：按章节跳转。
- 书签：给当前位置加书签，可以随时取消；书签按位置排序，滑动删除。
- 搜索：输入关键词，结果显示位置和摘要，点击跳到原文。

阅读时页边的丝带标出当前页的书签。

## 字号与主题

- 「字号」调整正文字号。
- 「主题」可选「跟随系统」「浅色」「深色」。

## 阅读进度

阅读位置会自动保存。退出阅读器再打开，会回到上次读到的位置；切换翻页方式、调整字号都不会丢位置。
