# 阅读

## 打开与继续

书架点封面打开一本书；每本书单独保存阅读位置，再次打开时恢复。不再提供单独的「接着读」卡片。

## 翻页与工具栏

- 「阅读设置」中选择 EPUB 的「分页」「滚动」或「仿真」；滚动模式可沿上下方向跨章节阅读。
- 轻点未标注的正文，收起或显示工具栏；也可点专注图标隐藏工具栏。
- 工具栏隐藏后，再点正文即可恢复。

目录、阅读设置和问答以弹层打开，可上拉展开到全屏。

PDF 支持双指缩放，阅读设置提供「分页」和「滚动」，不提供字号调整。尚未设置时，200 页及以上默认分页，较小文件默认滚动；这不是大文件性能保证。

## 目录、书签与书内搜索

打开底部工具栏的「目录」：

- 「目录」按章节跳转；没有目录的 PDF 显示页面。
- 「书签」查看、回跳和删除已有书签。阅读器右上角书签按钮是添加或取消当前位置书签的入口。
- 「标注」查看当前书的高亮和笔记，详见[标注与笔记](annotations.md)。

在目录弹层点搜索图标，输入关键词查书，点结果回到原文。PDF 只能搜索有文字的页面，扫描页不支持 OCR。

## 字号与主题

在书内「阅读设置」调整 EPUB 字号和明亮／深色主题，立即作用于正在阅读的正文，不需要另看示例。「我的」不再重复提供阅读外观设置。

## 阅读进度

阅读位置会自动保存。退出后重新打开、从目录或标注回到原文时，仍可继续阅读。字号或阅读方式变化会按原文位置恢复，重新排版后的页码可能改变。
